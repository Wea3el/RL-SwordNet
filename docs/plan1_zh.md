# RL SwordNet 项目框架与初期报告说明

更新日期：2026-11-22。初期报告面向 2026-12-03 最终报告的整体研究方案。仓库：[RL-SwordNet 的 plan1 分支](https://github.com/Wea3el/RL-SwordNet/tree/plan1)。队友可直接摘取[英文报告草稿](report_draft_en.md)对应章节；[历史方案](plan1_20261121_zh.md)仅供追溯。

## 项目简介与研究问题

项目面向体育练习中的交互式持剑训练目标，在 MuJoCo 中构建两台固定底座、各持一把竹剑 shinai 的七关节机械臂。当前不使用躯干、轮式移动或相机观测。主要研究：在相同机器人、底层控制、可用物理观测和计分条件下，有限动作先验与连续关节探索会怎样影响有限预算内的学习效率、攻防表现及灵活性？

最终比较的是两种分别通过 self-play 训练的策略，而不是固定脚本与学习策略，也不是已完成的模仿学习专家与 RL 的对比。该实验同时改变动作先验和动作空间，不能据此声称某个 RL 算法或某种武术更优。Germanic／HEMA 风格重建不是当前主线，也不把 ASE 动画称为历史剑术专家数据。

## 两类策略与共用仿真框架

| 项目 | A1 技能选择策略 | A2 连续关节策略 |
| --- | --- | --- |
| 策略输出 | 已验收技能的选择及启动时机 | 七个关节目标的连续增量 |
| 运动来源 | ASE-derived 候选，经重定向、改造与物理验收形成有限库 | 从受限连续动作空间中探索，不依赖 A1 库选择运动 |
| 学习内容 | 何时保持、格挡、进攻，如何接续合法技能 | 运动生成及攻防决策 |
| 训练对手 | 冻结的历史 A1 类型策略 | 冻结的历史 A2 类型策略 |
| 最终评估 | 冻结策略后与 A2 交叉对打 | 冻结策略后与 A1 交叉对打 |

A1/A2 是策略类型，不是场景中固定的左右位置。A1 self-play 时，两台机器人均可运行 A1 类型策略。单个技能的内部轨迹固定，不等于整场战斗播放固定动作序列；组合和时机应由策略学习。A2 不会被限制为 A1 库内的动作。

两种动作适配器最终都产生关节目标，交给同一原生 position actuator 控制与 MuJoCo 动力学执行。没有中途覆盖实际 `qpos`、脚本拨剑或碰剑免伤。双方共用关节、速度／目标变化率和力矩约束；当前调试力矩、假设的 ±π 关节范围及 CAD 质量惯量尚不是实机标定。

无视觉阶段使用仿真当前状态：自身关节位置、速度和控制状态，以及对手握点／剑尖的相对位置、速度或短期历史。不给策略对手未来轨迹、隐藏技能标签或脚本结束时刻。共同训练观测仍需完成封装；自身编码器并不能在实机上直接测得对手，实机反馈另需传感或双方状态通信与标定。

## 工具与数据

- [MuJoCo](https://mujoco.readthedocs.io/en/stable/overview.html)：刚体动力学、原生执行器和武器接触；本地验证使用 3.4 系列。
- Python、NumPy 与项目内数值工具：实际握点／剑轴 FK、五维工具空间 IK、轨迹插值和记录。在线 Pinocchio IK 不是当前依赖。
- [ASE 项目](https://xbpeng.github.io/projects/ASE/index.html)及其 [Reallusion 动作目录](https://github.com/nv-tlabs/ASE/tree/6f9b4f1f289603eee6a4f45d082bc6e6d83fecec/ase/data/motions/reallusion_sword_shield)：仅作为 A1 动作姿态种子，不复现其完整对抗模仿学习框架或使用人形预训练策略。
- 拟使用 PPO 训练两类策略；训练库、版本和超参数在环境验收后固定，目前没有训练完成的网络或可用训练命令。
- Git/GitHub 保存代码、配置与说明。第三方 motion 二进制、衍生轨迹、视频及大型模型转储不随本次提交发布。

动作数据没有本机器人对应的关节角、同步对手或胜负标签。转换时按来源哈希和大小核验，用受限数值解码器读取；从右手代理握点和剑轴生成参考，经过共同空间标定、明确的位移幅度适配、关键姿态提取、平滑和重新定时，再对真实七关节模型求 IK。源手至剑节点约 0.74 m，而机器人握点至剑尖固定为 0.79 m，不通过缩放机器人或竹剑来迁就数据。

## A1 动作库与验收

当前已生成 Ready、Stab、单侧横斩、左右拨挡共五个 A1 几何候选。共同标定后五项均通过采样 IK 与严格代理碰撞检查；这不证明动态命中、有效格挡或连续切换。原文件名 Left/Right 和镜像换边也不构成来剑方向覆盖证据。

下一步拟扩展为 Guard、直刺／左右横斩／下劈，以及左右／上下防守。是否增加斜向或高度变体由实际覆盖表决定，不以动作数量宣称覆盖完整。每条动作及其保持、返回、反击衔接都必须验收：

1. 攻击对相同初始条件下的 Guard 对照确实命中，不能空挥。
2. 防守须在基线命中前原生拦截；整段有效剑身在完整威胁及退出窗口内不入靶。方向选对、发生碰剑不能获得免伤。
3. 保存适用攻击范围、启动采样、真实接触阶段和早／晚／错误方向反例；进一步测试小扰动和独立 A2 连续攻击。
4. 实际关节必须连续进入、退出和衔接，不能把末端位置回到 Ready 当作七关节已经闭环。

有限动作库不保证挡住 A2 的任意合法攻击。应区分库的能力盲区和策略选错／启动太晚，并在最终评估前冻结动作及规则，不修改能力直到 A1 获胜。

## 计划实现的算法与规则

拟采用 [PPO](https://arxiv.org/abs/1707.06347)，从环境交互轨迹更新策略与价值网络。A1 使用离散技能输出，A2 使用连续关节增量输出；两者分别进入同类型历史策略池 self-play。单局对手保持冻结，定期保存快照并采样旧对手；固定／随机策略只作调试对照，不冒称 self-play。

训练奖励以合法得失分和终局结果为主，辅以小幅控制变化／能耗代价；不按选中某个 pose、碰剑次数或更大撞击力奖励防守。完整训练奖励、犯规归因、reset／step、归一化与终止／截断接口尚未实现，需先检查等待、重复攻击、数值故障逃分等漏洞。

已实现的显式 v2 计分组件使用护手远端至剑尖的三段实际圆柱剑身进入虚拟球靶的检测，与技能 ID／Attack 阶段无关。剑刃与对方护手接触是合法中性武器接触，不直接得分；其他机械臂／底座接触另行处理。首个有效命中结算，同一物理步双触为平局；数值故障／非法物理试验记为无效而非普通零分平局。技能验收在首击后仍继续完整模拟，保留迟发入靶，避免提前结束掩盖漏防。该组件尚不是完整 RL 环境。

主要实验比较冻结 A1 与 A2，交换位置、使用独立评估种子，报告胜／负／平、有效攻防、犯规／无效比例及学习曲线。训练预算按模拟时间与物理步比较，而不是将一条长宏动作视作一个等价训练步；若用可变时长宏动作，需要相应累计奖励和处理折扣。目标为多独立训练种子，预算不足则报告真实数量和限制。

防守表现首先用有效回合的被命中率及受控配对攻击的全窗口保护结果衡量，不按技能标签统计。无效试验单列比例，不混入普通平局；正式训练中的犯规归因与后果须在训练前冻结，避免制造逃分途径。

在预算允许时比较历史对手池与仅最新快照，测试未见时机／已验收攻击变化及双方始终等待／攻击／防守的对照。覆盖测试中可离线搜索最佳防守时机估计能力上界，但在线策略只读当前可用状态，不能读取对手未来。

## 预期结果与伦理边界

研究假设是 A1 的技能先验可能提高早期学习效率，而 A2 的连续动作空间可能带来更大灵活性、也增加探索难度；两者均是待检验假设，不承诺胜率或某方胜出。预期交付包括可复现仿真、经验证的有限技能、两类训练／交叉评估材料及负结果分析。任何阶段未通过，应报告阻塞并与团队讨论范围调整，不能暗改规则、删去对手能力或将脚本称为训练成功。

项目限于教育与体育仿真，承认持棍机械臂的碰撞风险和双重用途。不锋利的竹剑、ArUco 识别或拟议阻抗控制都不证明人机接触安全；当前没有部署认证、经验证的柔顺控制或实机迁移结果。真实部署另需惯量／限位标定、限力、急停、柔性碰撞与感知验证。
