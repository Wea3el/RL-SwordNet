# 手工进攻与拨挡的 MuJoCo 验证

本页保留早期角色专用人工对照，A1/A2 在此表示攻守机器人位置，不是最新两类学习策略。该实验的剑尖计分与角色专用轨迹不能直接当成当前 A1 技能库或 A2 连续控制；当前范围见[项目框架](plan1_zh.md)和[v2 验收说明](skill_validation_zh.md)。

当前版本已经验证一组具体的直刺与侧向拨挡：不防守时直刺命中，采用合适时序的拨挡后，同一进攻在完整进攻及回收窗口中没有命中。它不依赖 ASE 或其他动作数据集，是后续训练“何时发动技能”的机械测试基线，还不是学习策略。

## 场景和动作

两台完整机械臂底座固定在地面，相距 1.75 m，相向放置，不添加人体躯干。原 CAD、机械臂、夹具和竹剑都不缩放。竹剑全长 1.080 m，实际夹持点到剑尖 0.790 m。

| 动作 | 定义 | 默认时序 |
| --- | --- | --- |
| Guard 警戒 | A1 水平朝前持剑；A2 竖直持剑并偏离进攻线，两剑初始无接触 | 初始保持 0.75 s |
| Attack 直刺 | A1 夹持点沿自身 +X 从 0.30 m 到 0.65 m，剑轴保持 +X，夹持高度 1.05 m | 前进 4 s，伸展保持 0.4 s，再沿原路回收 4 s |
| Parry 侧拨 | A2 自身坐标的夹持点从 `[0.50, -0.25, 0.75]` 到 `[0.50, +0.20, 0.75]` m，剑轴保持竖直；在世界坐标中从 Y=+0.25 扫到 −0.20 m，跨过进攻线 | 比直刺晚启动 1 s，侧拨 2 s，保持到攻击回收后，再用 2 s 返回 |

三者是**角色专用的动作定义**，不是任一机器人可以直接任意切换的统一 `0/1/2` 控制器。A1 的水平警戒位和 A2 的竖直警戒位不同；目前验证了各自前进及原路返回，没有验证两警戒位之间、进攻与防守之间的转接。接 RL 前必须补上这些转接，或先将学习任务限制为 A2 在警戒和侧拨之间选择启动时机。

任务空间路径采用五次平滑插值，使用真实夹持点与剑尖求连续 IK，每条前向路径保留全部 81 个采样点。初次放置直接 reset 到警戒位；CAD 零位走到警戒位的路径不在这次验证范围内。

## 什么算成功防守

每个条件运行两个完整物理回合：A2 保持警戒，以及 A2 执行侧拨。初始状态完全相同，A1 每个控制周期的目标关节角完全相同，并记录 SHA256。接触或命中事件都不会停止进攻、改变命令或重置姿态。

虚拟靶心位于防守方底座朝内 0.32 m、高 1.05 m 处。靶球半径 0.06 m，加上 0.01 m 的评分剑尖半径，有效计分半径为 0.07 m。靶只是 site，不产生碰撞力。每个物理步都对前后剑尖位置做扫掠检测，避免剑尖跨过目标却漏判。

只有同时满足以下条件才记为成功：无防守回合命中；防守回合全程不命中；在无防守的命中时刻前已经出现实际剑刃接触力；接触冲量达到诊断阈值；两回合均未违反速度、力矩、接触或数值检查。碰剑但依旧命中、过晚碰剑、原本就打不中，都不算成功。

这次计分针对直刺的剑尖。其他斩击、有效部位和连续攻防需要另外定义规则，不能直接沿用本次结论。

## 动力学与约束

初始化以后只使用原生执行器控制和 `mj_step` 推进，不逐帧写入关节位置，不施加脚本偏转、外部广义力或刚体重力抵消。模型重力前馈也经过原有执行器力矩上限。

原增益 `[2000,2000,2000,2000,200,200,200]` 和力矩上限 `[5,80,15,20,3,3,2]` Nm 保持不变。这些力矩是原项目的调试参数，不是已经确认的实机规格。参考指令限速 1 rad/s，实际速度超过队友给定的 2 rad/s 则判试验无效。关节角范围仍是假设的 ±π，不能作为硬件行程证明。

物理步长 2 ms，控制周期 10 ms。保留原有单臂邻接过滤；两机器人之间所有碰撞代理均允许接触。只有剑刃对剑刃是本实验的合法接触，剑柄、夹具、机械臂互撞或碰地出现超过 0.5 N 的接触力时试验无效。代理穿透超过 5 mm、跟踪误差超过 0.5 rad、数值警告等也会使试验失败。阈值用于诊断，不是人体安全标准。

## 实际结果

默认回合运行完整 11.85 s，其中攻击及回收在 9.15 s 完成。

| 检查 | 结果 |
| --- | --- |
| 同一进攻，不防守 | 约 3.5223 s 命中，最近剑尖距靶心 6.67 mm |
| 默认侧拨 | 约 2.820 s 首次实际碰剑，全窗口不命中，最近距靶心 163.37 mm，大于固定 70 mm 计分半径 |
| 交换两台机器人的角色 | 默认侧拨仍成功 |
| 故意晚 4 s 才启动侧拨 | 进攻命中，正确判为失败，不因后续碰剑获分 |
| 步长从 2 ms 减为 1 ms | 默认及镜像仍成功，晚防守对照仍失败；默认最近距靶心约 163.44 mm |

默认防守的剑刃峰值接触力约 11.51 N，法向冲量约 21.87 Ns；最大实际关节速度约 1.016 rad/s，无非法接触力、无 MuJoCo 警告，输出力矩没有超过原上限。部分执行器会饱和，最大关节跟踪偏差约 0.178 rad；被拨开的效果包含现有有限力矩模型的顺应性，不是完美位置跟踪，也不是已经校准的真实柔性。

第一组“将竖剑移到中线上就停住”的方案失败：虽然碰剑，直刺仍进入靶区。它的证据保留在 `outputs/manual_duel_round1`；成功版本改为持续横向扫过中线，没有缩小目标或提高力矩。

### 时序和速度敏感性

冻结成功动作后，额外测试了相同的六个启动延迟：0.90、0.95、1.00、1.05、1.10、1.20 s。

| 进攻速度倍率 | 固定六个延迟下的通过数量 | 含义 |
| --- | --- | --- |
| 0.8× | 0/6 | 拨挡过早，剑先扫过去了，未发生有效拦截 |
| 1.0× | 6/6 | 这些离散时机均能保护目标 |
| 1.2× | 6/6 | 这些离散时机均通过，但最小裕量仅约 2.4 mm，不能作为宽裕的可靠区间 |

另外按已知动作相位对齐拨挡中段，0.8× 使用 1.5 s 延迟、1.2× 使用约 0.6667 s 延迟，两组均通过。这里利用的是预先知道的脚本时序，不是视觉检测、反应策略或学习成果。它说明“动作本身可以挡住，但发动时机必须与来剑匹配”。

默认 `--matrix` 另测 0.9×、1.0×、1.1× 速度与 0.8、1.0、1.2 s 延迟，加上镜像和晚防守对照，共 11 对有效试验，其中 7 对成功，其他保留为有效的失守记录。不能把包含故意失败对照的这个比值叫自博弈胜率，也不能从确定性网格推导随机成功概率。

## 本地复现和输出

在仓库根目录运行，输出目录必须是新的：

```bash
python -m sim.manual_duel --output outputs/manual_duel_new --matrix
python -m unittest discover -s tests -v
```

命令返回成功要求默认与镜像防守成功、晚防守对照按预期失守；网格中的时机不匹配结果不会被删除。动作参数在 `sim/manual_skills.py`，时间及诊断参数在 `config/manual_duel.json`。可以用 `--config PATH` 和 `--geometry PATH` 读取独立参数文件，但几何目标必须与场景目标一致。

每次试验保存 `summary.json`、独立场景 `scene.xml`、`runtime_config.json`、`geometry_config.json`、`manual_paths.npz`；每个条件分别保存无防守和拨挡回合的 `summary.json` 以及实际 `trajectory.npz`。记录实际关节状态、命令、执行器输出和剑刃力，不只保存成功帧。原 CAD 和实现文件的哈希也随报告保存。

用录制的实际物理状态生成并排回放，而非播放 IK 目标动画：

```bash
MUJOCO_GL=egl python -m sim.manual_duel_replay --run outputs/manual_duel_new --output outputs/manual_duel_new/comparison.mp4
```

视频渲染额外使用 `imageio` 和 `imageio-ffmpeg`（可用 `python -m pip install imageio imageio-ffmpeg` 安装），不影响无界面物理测试。回放读取该次试验保存的 XML，按实际时间插值日志状态，不重新计算或修改胜负。

本地本轮完整证据在 `outputs/manual_duel_final`。更小步长在 `outputs/manual_duel_dt1ms`；额外 18 对时序测试和两组相位对齐测试分别在 `outputs/manual_search_core_matrix_01`、`outputs/manual_search_core_phase_01`。这些输出被 Git 忽略，源码可以重新生成默认测试；不要将尚未上传的本地文件当作 GitHub 已有附件。

## 接下来可以训练什么

最小学习任务可以固定 A1 的直刺脚本，让 A2 学何时从自己的 Guard 发动 Parry。训练时改变进攻启动时间与少量速度，评估时保留未见过的时序组合，并与固定时序基线比较。先不要要求网络从零发明关节轨迹，也不要把固定 A1 对手训练称为自博弈。

扩展到双方都能进攻和防守之前，需要补齐警戒位及技能间转接、非剑尖命中规则、机械臂合法活动范围，以及实测力矩与速度信息。本轮仅验证刚性竹剑和粗碰撞代理下的受控拦截，不能证明实机可行、对人体安全或任意来剑可防。
