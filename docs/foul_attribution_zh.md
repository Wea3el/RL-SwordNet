# 犯规运动归责的离线验证

本页保留“犯规终止并罚分”的离线候选和原始验证。用户随后已明确同意将该约定接入新的训练环境，当前接入层为 `sim/training_contacts.py` 和 `sim/a1_env.py`，见 [最新进度与边界](a1_readiness_zh.md)。`sim/foul_attribution.py` 仍是原离线纯函数，不改变旧计分器或原生验收；旧 v2 的无效记录不改写。归责是固定底座世界坐标系下的约定，不是意图识别或物理因果证明。

## 候选结算规则

| 事件 | 候选训练收益 | 候选胜负 |
| --- | --- | --- |
| 合法剑刃／护手接触 | 双方 0，不结束 | 不直接得分，也不产生免伤 |
| 单方明确主动非法接触，另一方静止或退让 | 责任方 −1，对方 ＋1 | 对方犯规胜 |
| 双方主动或责任不清的非法接触 | 双方 −1 | 无赢家，单独记录双犯规／不明确犯规，不算普通零收益平局 |
| 自碰或碰地，证据可靠 | 所属机器人 −1，对方 ＋1 | 按明确的所有权约定归责，不声称识别受力因果 |
| 数值故障或不能使用的证据 | 不生成正常收益 | 报错，无虚构赢家 |

同一物理步内的多次接触统一合并一次，不叠加处罚；同一步命中与犯规同时发生，犯规优先。一个更晚物理步的故障不能通过本模块推翻已经结束的正式首击回合。完整动作验收继续保存后续 shadow 和故障，属于另一层证据。

调用方必须先收集整步接触及合法碰剑历史，再生成归责输入，不能让接触遍历顺序决定“之前是否受拨挡影响”。纯结算函数的顺序无关，不自动保证上游输入也是顺序无关。

双方 −1 的双犯规不是零和收益。训练收益、正式赢家和比赛积分是不同字段；比赛积分尚未在此模块定义。评估须分别统计靶区胜利、犯规胜利、双犯规及数值故障，不能把制造犯规造成的收益当作击剑技术提升。

## 运动证据与不确定性

本模块不检测碰撞，也不降低原有 `0.5 N` 非法接触资格门。调用方只能在原物理门触发时提交事件；结算 tick 是事件获得资格的时刻，不是缓存前态的时刻。

归责需要首次几何接触前、两个对应刚体物质点的速度，而不是剑尖、几何中心或已受冲量影响后的速度。法向按 MuJoCo 原始 geom 顺序由 A 指向 B，不能将名称排序后继续沿用原符号。碰点速度须包含旋转贡献 `v + ω × r`，也可用相应刚体的世界点 Jacobian 求得。

候选规则比较 `vA·n`、`−vB·n` 及二者之和。单方明显接近、另一方静止／退让且存在相对闭合，才允许单方归责。双方明显接近、几乎纯切向、闭合不足、先前合法拨挡可能影响运动或历史未知，都不产生单方赢家。速度判定阈值固定为 `0.001 m/s`，仅为当前离线候选常量，未做硬件／噪声标定。

可靠证据下，自碰／碰地按所属机器人负责，即使之前曾受对方作用力，这也是已明确的所有权规则。所有类型的输入证据本身不可靠时，都走证据错误而不生成收益；可靠但因先前拨挡或历史未知而无法归责的跨机器人接触，才按双罚约定处理。非有限数据、非单位法向或矛盾的重复事件不能混成正常胜负。

## 已验证的原生场景

新侧采复演了 26 秒库的双向同步 Stab／Slash。每案逐 2 ms 观察一次，共 5,128 个物理点；失败时间仍为 `10.254 s`。所有七个已存轨迹数组、动作目标 SHA、非法接触对和原生接触力均与无侧采试验逐 bit 相同，侧采没有改变实时状态、控制或外力。

首次触及时采用前一步 `10.252 s` 的刚体状态，将当前接触点映射为各刚体对应物质点后计算速度。这是 2 ms 前步近似，不是精确碰撞时刻。碰撞前及同一步没有合法碰剑历史。

| 场景 | Stab 碰点法向接近贡献 | Slash 碰点法向接近贡献 |
| --- | --- | --- |
| 原位置 | 约 0.268 m/s | 约 0.185 m/s |
| 左右镜像 | 约 0.269 m/s | 约 0.184 m/s |

两者均明显主动接近。纯规则的实际离线应用均得到双犯规、无赢家、候选收益 `(-1, -1)`；geom 换序并反转法向、左右旋转及物理槽位互换的判定保持一致。这不是看到“剑刃碰握柄”就单罚剑刃所属方，也不把旧的 `invalid` 记录改成某方反制成功。

当前安装 MuJoCo 3.4.0 的头文件定义和有限差分检查已独立核对：法向方向正确，物质点 Jacobian 速度与有限差分最大误差约 `2.64e-10 m/s`。这证明该离线速度计算的一致性，不证明运动归责就是唯一真实责任。

另做同一场景的 1 ms 配对：无侧采／有侧采的七个轨迹数组完全相同，均于 `10.254 s` 触发原生失败。使用 `10.253 s` 前态，两个法向贡献约为 `0.267523 / 0.185349 m/s`；原固定阈值的纯规则仍判双犯规、双方 −1、无赢家，geom 换序结果不变。该配对只与相同 1 ms 配置比较，不假称两种物理步的轨迹逐 bit 相同。

## 复现与后续边界

```bash
python -m unittest tests.test_foul_attribution -v
```

契约测试覆盖单方／双方接近、追赶退让、切向和近零运动、旋转点速度、先前拨挡的不确定性、geom 换序、左右旋转、多接触、重复事件、同一步命中及数值故障。原生证据保存在本地：

- `outputs/a1_foul_preimpact_sidecar_round1/`：逐物理步数据、同条件原生复现和碰点输入。
- `outputs/a1_foul_preimpact_sidecar_round1/conventions_and_kinematics_audit.json`：本地头文件 SHA、法向和 Jacobian 核验。
- `outputs/a1_foul_attribution_offline_round1/summary.json`：两个真实场景的纯规则应用及换序／镜像不变量。
- `outputs/a1_foul_preimpact_sidecar_dt1ms_round1/summary.json`：1 ms 原生敏感性与只读复现。
- `outputs/a1_foul_attribution_offline_dt1ms_round1/summary.json`：1 ms 输入按原固定阈值的离线判责结果。

这套离线证据本身不批准训练，也不替代动作的物理验收。当前新环境已完成真实双犯规回归，横斩防守的后续结果见 [最新进度](a1_readiness_zh.md)；单方犯规、延迟达力门及碰剑后归责仍需扩大原生覆盖。正式积分映射与犯规收益投机检查继续独立于旧的严格验收记录。
