# A1 和 A2 共同评分规范提案

日期：2026-11-23。状态：待确认的规范，不是已部署规则。机器可读版本见 [评分规范 JSON](../config/scoring_spec_v3_proposal.json)。四项最终要求、位置覆盖与独立能力门槛见 [Plan 2](plan2_zh.md)。

推荐先采用一套简洁、双方一致的任务：两个固定机械臂以有效剑身先触及对方的虚拟躯干区域得分，不按动作名称判分，不增加实体躯干，不引入击打力度门槛或击中后的战术还击窗口。它评价的是有限时间内的合法触碰攻防，不宣称等同于完整 HEMA 比赛或实机安全。

评分先明确目标，再据此选择动作数据、构建可靠连续 pose、验证攻防并训练。下面的取舍同时考虑 A1 的有限技能和 A2 的连续关节控制，而不是只服务于现有 A1 轨迹。

## 推荐的共同规则

| 项目 | 首版建议 | 理由与下游影响 |
| --- | --- | --- |
| 计分区域 | 紧凑虚拟躯干，三个球的并集；首版暂不计头部 | 覆盖多个高度而不只一个小球；三个分区均有独立静态关节配置入区见证。暂不扩大尚缺攻防覆盖的头部范围，这是需确认的任务取舍 |
| 合法命中 | 现有三段有效剑身首次进入对方区域 | 刺、横扫、上下扫均可适用；不读 A1 技能名，不排除 A2 新轨迹 |
| 力度与速度 | 不设最低门槛，记录入区材料点速度用于分析 | 虚拟区域没有碰撞力，当前也没有可标定的有效切击阈值。慢速合法触碰可以得分，不能事后称为作弊 |
| 碰剑 | 刃与刃、刃与对方护手为合法中性接触 | 不直接得分、不产生格挡免伤；仍以是否拦住后续入区判断实际防守 |
| 正式终止 | 首个有效终局物理步统一结算后结束 | 避免 A1/A2 使用不同胜负语义；动作验收另外观察完整回收 |
| 双击 | 固定 1 ms 物理步内双方有效命中，双方 0、无赢家 | 沿用现有简单结算，不额外等待后续步。承认它依赖固定数值配置，不能声称步长无关 |
| 战术还击 | 首版不设置 afterblow 窗口 | 避免新增首击后犯规、故障和第二击归属冲突；后续若研究还击，另开规则版本 |
| 回合上限 | 候选 30 s | 当前低挡从触发到归位约 10.1 s，30 s 为连续决策留出空间；不是按最短演示片段设截断。新库变更后仍需复核 |
| 犯规 | 保留已批准责任约定，同一步犯规优先命中 | 不因评分区域改变而豁免柄、机械臂、底座或地面接触 |
| 训练辅助 | 正式任务先保留共同终局收益，不额外奖励动作次数或格挡标签 | 防止 A2 高频输出刷奖励或 A1 仅选择防守名称获利；预训练若加辅助，单独说明和核算 |

这些都是待确认选择，尤其是躯干范围、暂不计头部、触碰制、固定步长的双击约定和 30 s 上限。它们不能只因写进 JSON 就进入训练。

双方共用开局准备阶段：在同一已验证姿态下，用相同控制器等待共同就绪条件，不让 A2 先动而 A1 仍等待技能就绪。双方就绪后才开启正式比赛时钟和策略选择；准备阶段仍计入模拟交互成本。准备超时或初态不合法属于重置失败，不能记某方输赢。就绪容差沿当前执行器标准作为待复验值，最大准备时长在集成时显式配置，不允许无限等待。

## 靶区几何与可行性依据

底座间距保持 1.75 m。物理槽位 `a1` 的三个球心为 `(0.32, 0, 0.90)`、`(0.32, 0, 1.05)`、`(0.32, 0, 1.20)` m；槽位 `a2` 的 X 坐标为 1.43 m，Y、Z 相同。每球半径 0.12 m。槽位名称不代表策略家族：最终 A1/A2 要交换场地侧。

这是一块固定练习计分空间，不是人体尺寸模型。球并集的总体高度为 0.78 至 1.32 m，最大横向宽度为 0.24 m。区域交叠、三段剑身同时进入或跨区域滑动不能重复计一次命中。初始状态中，任何一方剑身已在对方区域内则重置无效。

区域本身不产生质量、接触力或额外自身碰撞规则。自身剑身进入自己的虚拟区域不新增罚分；已有真实代理自碰规则保持不变。这个简化必须公开，不能把虚拟区域解释成不可穿透的人体。防守方用机械臂遮挡造成对方犯规的策略风险，需要在平台验证中专门检查。

新增审计没有用 A1 动作库作为搜索起点：768 个关节向量做双侧镜像检查，共 1536 次计入预算的静态前向运动学，未随机抽中目标；随后从最近无代理重叠的随机状态做目标导向局部搜索，额外 20 次前向计算，找到了三个分区的静态入区见证。

| 分区高度 | 剑身入区深度 | 最近关节边界余量 |
| --- | --- | --- |
| 0.90 m | 30.449 mm | 0.060 rad |
| 1.05 m | 9.427 mm | 0.050 rad |
| 1.20 m | 18.506 mm | 0.050 rad |

三个状态在两侧均无代理接触；共同准备位的目标区域也没有与守方代理相交。这证明目标不是只能由 A1 的既有轨迹触及，但不证明存在从准备位安全到达的动态路径。随机采样没有命中也不等于 A2 学不会，更不是不可达证明。

公开证据：[Plan 2 摘要及原报告指纹](plan2_verification.json)。原始本地报告位于 `outputs/scoring_design_v1/reachability/report.json` 与 `outputs/scoring_design_v1/reachability_refinement/report.json`，未随 Git 分发；可按根 README 从当前源码重新生成静态检查。

三个球的并集是连通区域，不能因为画了三个球就声称有多个独立得分点。Plan 2 增补实际入靶点分区统计和双方公开的激活子区专项；专项与自由对打分开，不能混合胜率。六个统计格尚未逐格验证动态可达性；本节三个静态见证也不能代替这一验证。自由对打若始终集中一个点，仍未满足多位置目标。

## 收益与事件顺序

| 事件 | 训练收益 | 正式结果 |
| --- | --- | --- |
| 单方合法命中 | 命中方 +1，对方 −1 | 命中方获胜 |
| 同一步双击 | 双方 0 | 双击，无赢家 |
| 明确单方犯规 | 责任方 −1，对方 +1 | 对方犯规胜 |
| 双方主动或可靠证据仍无法归责 | 双方 −1 | 双方犯规，无赢家，不当作普通平局 |
| 有效超时 | 双方 0 | 超时平局 |
| 数值或证据故障 | 不生成有效训练收益 | 错误，保留轨迹与计数 |

每步先完整收集事件，再按“数值／证据错误、已达资格门的犯规、合法入靶”的顺序处理。这个顺序是同一物理步内的优先级，不意味着后续步可以追溯推翻已结束回合。

正式结果冻结后，动作诊断仍可以继续保存迟发入靶与回收，但不更改比分。跨步等第二击不是本提案的一部分。因此旧有 0.7 ms 合成反例依然说明数值分组的局限；本提案通过固定双方相同数值配置控制比较条件，没有声称已消除该局限。

犯规胜、命中胜、双击、双犯规、超时和错误分别报告。不能只报告过滤错误后的胜率，也不能把迫使对方犯规一概宣传为格挡技术提升。

## 对 A1 动作库的约束

数据用于提供连续的准备、击打、随动和回收，不直接提供裁判标签。动作应覆盖刺击、左右或斜向切击以及上下方向的合法进攻，并为已纳入的威胁提供可执行防守和反击机会；具体数量取决于验证，不把不可达的历史命名姿态假装已完成。

现有低挡在紧凑躯干探针中约 3.432 s 已出现剑身入区，而原碰剑约 4.372 s，所以不能直接进入新任务。其修复目标是更早或不同位置的真实拦截，不能用“选了格挡”取消对方命中。已有其他动作也要按新区域和最终共同控制链重新验收。

## 对 A2 的约束与训练路线

A2 输出有界七关节目标增量，不直接写仿真位置或速度；它和 A1 使用相同物理、低层控制、可用物理观测及裁判。详见 [A2 系统设计](a2_system_design_zh.md)。

先完成命令接口和安全探索测试，再用不含专家动作的到达／运动课程帮助 A2 建立控制能力，随后进入共同正式规则下的自博弈。课程不是最终对打成绩，额外训练交互计入总成本。A1 的数据处理和动作准备成本也单列，不能把结论写成单一 RL 算法优越性。

本阶段不同时开展多套主规则的长训。需要研究头部、还击或速度门槛时，把它们作为后续明确的规则实验，而不是边训练边改裁判。

## 必须通过的系统关卡

1. 新区域的连续入区检测、重叠去重、初态、边界和同一步多事件测试。
2. 多方向攻击对保持、对应防守、错误方向、过晚启动、镜像与轻微扰动；完整回收窗口与正式 30 s 时钟分开记录。
3. A1 与 A2 的共同命令链复验；A2 零动作、边界动作、持续撞限位、受阻累加和故障处理测试。
4. 始终等待、反复进攻、反复防守、机械臂遮挡、制造双方犯规及制造数值错误的反例检查。
5. 短训练验证采样和结算，再冻结版本长训；最后交换槽位，并使用共同未见对手与种子评估。

这些关卡没有通过前，可以确认规范方向，但不能把平台标为可正式训练，更不能声称 A2 或双机对打已经可靠。
