# 共享技能有效性验证

## 当前方案与动作库验收

最新方案是 A1 和 A2 都通过 self-play 训练：A1 学习选择及定时执行预先定义的有限技能，A2 输出连续关节目标增量。两者共用物理模型、底层控制、可用物理观测和计分规则，最终冻结策略交叉对打。下文的共享三技能试验是历史动作空间诊断，不代表这一训练架构已经完成。

这里的 **A1 指策略类型，不是场景中的固定机器人槽位 `a1`**。A1 自博弈时，两台机械臂都可加载 A1 类型策略；A2 自博弈使用连续关节指令。ASE 候选的配置、导出元数据及每个技能均明确标注 `policy_family=A1`，不能将其当作双方共同的最终动作限制。历史报告中 `a1/a2` 的镜像交换只表示物理位置和攻守互换，不等于多个攻击方向。

A1 的闭环关节库、仅使用自身反馈的执行器及原生物理验收入口已实现，见[当前 A1 执行与复现说明](a1_execution_zh.md)。后续 26 秒人工拨挡已对指定 Stab 建立当前观测触发的连续全窗防守正例，含镜像、延迟开打与 1 ms 复验；旧提前启动结果不能直接当成可见反应。合法但首击输掉的连续反击、扰动盲区及横斩反制缺口见 [A1 防守动作构建与验证](a1_defence_zh.md)。旧几何候选与人工攻防的证据范围不自动扩展为新库认证。

因此，动作库已经开始设计并有可复现原型，但尚不足以支撑本项目要求的合理自博弈比较。源文件名的 Left/Right 也不是机器人实际可防来剑区域的认证，需在机器人局部坐标下实测标定。

下一阶段建议的最小方向集合是：一个 Guard，直刺／左右横斩／下劈四类进攻，以及左右／上／下四类防守；这是扩展目标，不是已完成的九技能库。是否还需斜向或高度变体，应由实际攻击与防守覆盖表决定，不能靠技能数量宣布覆盖。

推进训练前须完成：每类进攻对 Guard 能命中；每类有效威胁都有实测可用的防守选择和启动窗口；返回与反击衔接合法；始终等待、始终攻击、始终防守不能靠环境漏洞占优。随后才接入共同观测／计分／底层控制、A1 有限技能与 A2 连续指令两种适配器、同类历史策略对手池，以及冻结后的 A1 对 A2 交叉评估。A2 的独立连续攻击也须参加覆盖检查，不能把 A2 限制为 A1 库内的动作来回避盲区。

用户已确认计分 v2：护手远端到剑尖的有效剑身可命中原有球靶；跨机器人剑刃与护手接触是中性的合法武器接触，不直接得分。柄、机械臂和底座等其他接触仍不能冒充成功格挡。`whole_blade_first_touch_v2` 使用实际三段平端圆柱及半径，每个物理步检测扫掠，不再依赖 Attack 标签或攻击阶段。旧 v1 默认和失败结果保留；v2 必须显式选择。

正式比赛首触结束，双方同一物理步入靶为双触；技能验收则继续完整模拟并保存后续入靶事件。任何数值故障或非法接触都会使验收无效，不按普通零分平局处理。

**A1 只有方向正确还不算格挡有效。** 动作入库须满足：

1. 相同攻击打 Guard 的配对对照确实命中，排除空挥。
2. 在基线命中前发生原生武器拦截，因果冲量只累计到基线首次命中时刻，不拿很晚的碰撞补证据。
3. 在完整攻击准备、击打、保持、回收及防守退出窗口内，对方有效剑身没有入靶。接触后滑入、从侧面绕入或提前回收后再中剑，均是防守失败，不取消合法命中。
4. 在声明的来剑方向、高度、入口状态及启动采样范围内完成镜像、邻近时刻与小扰动测试；保留过早、过晚、错误方向和迟发中剑反例。
5. 防守后保持、回 Guard 和下一次进攻的衔接另行通过连续物理测试；一次受控成功不自动批准训练。

每个技能需要记录适用威胁、真实拦截阶段、已测试的启动时刻和失败边界。有限库不能保证挡住 A2 任意连续轨迹；超出覆盖范围属于动作库盲区，不能伪装成策略选择失败。几个成功离散采样也不是整个连续时间区间的数学保证。计分器的最小间隙数值是自适应采样诊断，不单独充当全时域的安全裕度证明；边界病例需要更细物理步复验。

ASE 为进攻和原始拨挡提供姿态种子；当前成功的竖剑拨挡则是明确记录配方的人工动作，不是 ASE 专家数据或模仿学习结果。数据命名、IK 拟合和动画播放都不能替代以上验收。先建立共同 Ready 和少量可用技能，再扩展方向覆盖；未经物理验收的候选不进入正式 A1 训练动作空间。

## v2 受控复验和 ASE 候选

新计分器已用真实三段剑身、每步原生状态重新验证旧人工对照。独立 1 ms 复验的双向攻击均约在 13.1223 s 命中；实际 8.360 s 启动的拨挡双向完整运行 32 s，均无有效剑身入靶。配对比较保持攻击指令、初始状态、模型、控制及阈值相同，只改变防守行为；基线命中之前的碰剑冲量约为 1.475 N·s。此结果仅覆盖该启动点和这条人工攻击，不是新 ASE 库或任意 A2 攻击的防守证书。

修复后的 2 ms 主复验包含 2 个无防守对照和 14 个格挡案例，均完整运行 32 s、无无效物理案例且运行源码哈希保持一致。双向各五个邻近启动采样均防住，实际启动时刻约为 8.260、8.300、8.360、8.400、8.460 s；双向过早和过晚反例仍被命中。这证明所测时序不是单个偶然点，但尚未覆盖所有中间时刻、小扰动、错误方向或新的 A2 关节攻击。

另一条 `Parry(7.5 s) → Attack(13.6 s)` 序列仍于约 15.1742 s 被原攻击者迟发命中，整条序列不通过验收；约 25.9623 s 的反击命中只保留为后续诊断，不改写首击胜负。旧计分器的 1 ms 边界搜索故障也保留为无效试验；修复只改搜索括区，不改距离、时间或命中阈值，真实原生端点已加入回归测试。

同条件补充对照只执行 `Parry(7.5 s)`、不反击，完整 32 s 没有入靶。两案的攻击命令、初始状态、模型及运行配置一致，13.6 s 之前记录的实际关节、速度、参考和控制也一致。因此在这个精确案例中，漏防发生于反击接续，而不是把另一个启动时刻的防守结果误作因果证据。该反击衔接不得入库；这不意味着所有格挡结束后都不能反击。

以下直至文末保留旧 v1 试验的范围、规则和原结果；其中的“当前”“本轮”均指该历史试验，不代表上面的 v2 规则或新的双 self-play 方案。不能将两版的命中时间、护手接触判定或推进条件混算。

## 结论与推进条件

2026 年 11 月 22 日的本地验证已经证明：双方共用三个技能时，存在能够命中的进攻和确实阻止命中的拨挡；拨挡有时机要求，不是任意播放都能免伤。分阶段准备的新候选也通过了已测试的双攻组合。

**连续对打仍未通过，因此暂不开始 RL。** 拨挡后立即反击会暴露于原攻击的回收段；等待对方剑退开再反击的候选，又在后续交互中发生剑刃撞护手。训练无法自动补上这些接触规则和切换路径的缺口。本次没有修改合法接触标准、放大模型、移动靶点或放宽碰撞阈值来消除失败。

本轮成果是物理动作空间的验证与问题定位，不是训练效果、自博弈成果或实机安全认证。当前三个技能是人工几何设计，没有使用 ASE 数据训练。

## 双方共用的动作接口

两台机器人都使用同一个 `SharedLibrary`。局部关节数组和技能时长完全相同；A2 仅通过固定底座的 180 度旋转与 A1 面对面。

| 动作 | 当前候选的执行方式 | 时长 |
| --- | --- | --- |
| 0 Guard | 保持唯一公共 Guard；忙碌时是继续执行，不取消动作 | 空闲选择 |
| 1 Attack | 竖剑移位、原地倾剑、刺出、短保持、回收、原路返回、冷却 | 28.1 s |
| 2 Parry | 横扫、固定自身保持、回扫至 Guard、冷却 | 6.1 s |

所有有限技能在指令空间精确从同一 Guard 开始并返回。实际关节状态只由 MuJoCo 原生执行器和接触求解推进；仅在试验开始时初始化到 Guard，中途没有关节重置。实际状态不被强行贴回参考路径。

这里的技能是完整轨迹，不是三个静态定格姿态。成功案例的有效碰剑发生在 Parry 的 `recover` 回扫阶段；不能把前向扫过、停在终点或只抽取一帧姿势称为已经验证的防守。

技能时钟只读自身经过的时间，不读取对手的结束时刻或未来动作。忙碌时不能重新启动、取消或瞬间切换；动作掩码保留合法的 `0=继续`，避免未来掩码策略出现全部动作禁用。当前实现还不是 Gym 环境。

## 几何和计分条件

现有 CAD 机械臂、夹具及竹剑模型的尺寸均未缩放。竹剑总长 1.080 m，握持点至剑尖 0.790 m；双方底座间距 1.75 m。原增益、调试力矩上限、代理碰撞体和碰撞掩码未改变。

虚拟靶心分别位于世界坐标 `[0.32, 0, 1.05]` 和 `[1.43, 0, 1.05]` m。靶半径 0.06 m，加上计分剑尖半径 0.01 m，有效半径为 0.07 m；靶是无质量、无接触力的测试标记，并非已经确认的最终比赛目标。

分阶段候选准备握点为 `[0.45, 0.20, 1.05]`，伸展握点为 `[0.65, 0.20, 1.05]` m；剑轴约为 `[0.967423, -0.253165, 0]`。握点到剑尖的 Y 位移抵消 0.20 m 偏置，仍朝原靶点进攻。刺出行程为 0.20 m。准备与回收总时长较长，是当前低速可行性试验，不代表最终击剑节奏。

几何检查包含完整 IK 行、关节插值代理碰撞和公共 Guard 接缝。当前限位为假设的 ±π，不是确认的实机机械行程。静态重力需求和实际速度／跟踪误差单独记录；本轮不因速度超过 2 rad/s 或跟踪误差超过 0.5 rad 就把几何姿态判为失败，但不允许借助未确认的限位约束力、外加广义力或关掉碰撞获得成功。

命中记录采用每个 2 ms 物理步的实际剑尖扫掠检测，而不是仅看视频帧或目标指令。每次被接受的 Attack 最多记一次，且须由靶外进入；起始已在靶内、非攻击阶段进入或静止占靶不能刷分。有效阶段为 `thrust / extended_hold / retract`，因此不能忽略回收中的迟发命中。同一物理步双方命中标记为双击。

当前保存的是命中事件，尚未实施 RL 奖励、胜负结算或回合终止。特别是双击不能在未来简单变成双方各自获得单边胜利。

## 分阶段候选的实测结果

主试验使用 2 ms 物理步、10 ms 控制和 100 ms 决策；独立重复使用 1 ms 物理步。独立试验均完整运行 32 s，覆盖进攻、拨挡和全部返回过程。

| 检验 | 结果 | 对后续的意义 |
| --- | --- | --- |
| 双向 Attack 对 Guard | 均在约 13.076 s 命中 | 进攻不是空挥 |
| 在刺出开始前约 2 s 启动 Parry | 双向完整防住，1 ms 重复也通过 | 存在对称、可重复的防守机会 |
| 上述 1 ms 防守的最近剑尖距靶心 | 88.34 mm，大于 70 mm 计分边界 | 不是仅仅碰剑或贴着边界漏判 |
| 提前 6 或 5 s 拨挡 | 无碰剑，仍被命中 | 防守过早会失效 |
| 刺出开始后 2 或 3 s 拨挡 | 先命中、后碰剑 | 迟来的碰剑不算成功防守 |
| 全部 3×3 同时动作组合 | 9 个均完整完成 | 不只单独检查攻击和防守 |
| 双攻相差 −4、−2、+2、+4 s | 4 个均完整完成 | 已覆盖部分不同攻击相位 |

独立最终集合的最大实际关节速度约 1.379 rad/s，最大跟踪误差约 0.196 rad，最大剑刃代理穿透约 1.73 mm；没有非法接触、额外关节重置或速度／跟踪诊断超阈。这些数值仅适用于该试验集合和调试动力学配置。

## 连续决策与失败原因

双方的规则／随机策略接收相同的观测类别：自身关节位置速度、自身技能状态，以及对手当前剑尖／握点的相对位置和剑尖速度。不提供对手未来脚本、下一动作或剩余时钟。这些是仿真真值观测，不能等同于已经实现的编码器通信或视觉感知。

规则拨挡使用当前下降的剑尖几何特征，之后尝试反击。该规则经过技能特征调参，不是通用击剑算法；固定策略的含义是不学习，而不是永远盲播序列。

| 连续试验 | 结果 | 当前判断 |
| --- | --- | --- |
| 拨挡结束后立即进攻 | 原攻击在 15.237 s 回收段命中，之后才有反击命中 | 不能把“刚刚挡住”当作可以安全放开 |
| 等待当前剑尖轴向退出后再反击 | 30.470 s 剑刃撞对方护手，约 5.41 N；镜像也失败 | 当前接触规则下无效，不能作为训练成功证据 |
| 重复 Attack 对重复 Parry，60 s | 进攻方两次命中，完整完成 | 一直拨挡并非自动免疫 |
| 规则策略对固定随机种子策略，60 s | 完整完成，双方各两次命中 | 部分连续组合可以执行，不能替代失败反击组合 |
| 两个规则策略，60 s | 完整完成，双方各一次命中 | 尚非多种子评估，也不是自博弈 |

等待反击的失败并非原来 ±2／±4 s 双攻测试已经覆盖：它涉及碰剑后的实际偏移、不同攻击相位，以及下一次进攻开始时对方仍在运动。名义关节路径无碰撞，不保证带接触历史的实际轨迹也无碰撞。

目前还没有证明“一直 Attack”可以被合法、稳定地反制获胜，也未排除双方等待的退化策略。不能用少数成功视频或未来奖励塑形代替这项验证。

证据位置：

- `outputs/shared_staged_critical_round4/`：立即反击的失败、完整双攻正例。
- `outputs/shared_continuous_round5/`：等待退出后的失败、镜像及重复拨挡对照。
- `outputs/shared_policy_mixed_round5/`：规则／随机和规则／规则连续试验。

## 下一步需要先解决的问题

先明确最终的靶区和武器接触规则：护手被剑碰到，究竟是允许的武器接触、犯规，还是必须通过动作规划完全避免？现有测试沿用“仅剑刃对剑刃合法，其他跨机器人接触不合法”，没有为了通过结果而改变它。若团队改变规则，需要作为新版本重新验证，不能混算旧结果。

在保留现有严格规则的情况下，应优先解决带接触历史的等待、反击与下一次进攻的路径／切换安全，再扩大相位与连续策略覆盖。不应单方面删掉对手攻击能力或禁止同时进攻来制造 A2 胜率。

之后才接入对称的 Gym 动作观测接口、回合结算／奖励、固定 A1 基线、A2 训练和历史对手池。只训练对固定 A1 不是自博弈；最终策略比较还需独立随机种子、未见过的对手时序和相同的能力／观测条件。
