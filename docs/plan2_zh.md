# Plan 2 多方向击剑与 A1 A2 公平比较方案

更新：2026-11-23。分支：`plan2`。本方案是后续实现、验收及报告的共同依据；不是“两个策略已经训练成功”的结论。

## 研究目标与当前结论

在同尺寸、固定于地面的两台七关节机械臂上比较两种学习方式：**A1 从预先验证的连续技能中学习选择和时机；A2 不接受专家动作轨迹，直接学习七关节目标增量。** 两者分别通过自己的历史策略池自博弈，最后冻结权重，在相同观测、控制、计分和对手条件下比较。

项目希望得到可连续攻防的练习机器人，而不只是播放姿态的视频。A2 的连续动作空间可能允许更细的方向、轨迹和时机调整，但也更难训练；“A2 更灵活”是要检验的假设，不是预设胜负。A1 应是有效且有竞争力的基线，不能靠故意薄弱的动作库证明 A2 优越。

当前已具备原尺寸模型、确认的角度边界、部分连续动作候选、旧规则事件测试和 A2 命令层离线验证。**新多区域裁判、完整新限位动作库、共同控制集成、A2 原生训练和最终对打尚未完成。** 因此先发布可审查的设计与证据，不启动长训。

## 四项最终需求对应的设计

| 最终需求 | 必须实现的内容及理由 | 验收方式，不以什么替代 |
| --- | --- | --- |
| 1. 自然、多个方向及多个得分位置的攻防 | 用连续参考和完整准备／击打／随动／回收构建动作；让得分空间容纳不同高度、左右位置及切击方向 | 实际运动方向和入靶位置覆盖、分方向防守成功率、完整原速视频；不能用姿态名、扩大一个球或精选成功片段替代 |
| 2. 检验 A2 自己学到更灵活的策略 | A2 无专家动作输入，允许连续关节探索；用未见来剑方向、启动时刻和位置变化测试适应性 | 与强 A1 基线比较成功率、响应时间及实际轨迹调整；动作抖动、动作熵大、对单个弱对手获胜不算灵活 |
| 3. 双方观测与得分公平 | 同物理状态快照、同局部坐标、同目标和裁判、同控制约束；训练与最终对打沿用同一正式任务 | 镜像交换、事件排列及边界反例、冻结测试集与裁判身份；不向任一方泄露对手未来动作 |
| 4. 两者单独没有明显性能缺陷 | 各自先证明能合法进攻、防守、回收和继续响应，再比较谁更强 | 分别通过控制及攻防测试；不能用最终胜率掩盖某方不会防守、卡住或利用犯规获胜 |

## 先定共同评分，再构建和验证动作

依赖顺序固定为：

**硬件与装配约束 → 共同评分规范及可行性 → 数据参考和连续动作 → 成对全窗口验证 → 共同平台与漏洞检查 → 分别自博弈 → 冻结交叉测试。**

改变靶区、控制器、限位、观测或时钟，都要列出依赖它的动作、训练数据和检查点，并重新验证受影响部分。不能通过修改评分来掩盖某次防守失败，也不能期待 RL 修好不可达目标或不提供反应机会的动作库。旧证据保留其原始条件。

### 共同比赛规则候选

详见 [评分提案](scoring_spec_v3_proposal_zh.md) 和 [JSON](../config/scoring_spec_v3_proposal.json)。这些参数仍是候选，发布到 GitHub 不等于启用。

- 保持原尺寸机械臂、1.080 m 竹剑和 1.75 m 底座间距。J0–J6 使用 [已确认同零位、同正方向的边界](../config/joint_constraints_observed.json)。不为了人形外观缩放机械臂或剑。
- 首版候选得分区是三个半径 0.12 m、中心高度为 0.90/1.05/1.20 m 的球并集，左右槽位镜像。它只是固定的虚拟练习区域，不是实体人体；首版不加头部、手腕或机械臂得分区。
- 有效剑身首次合法进入对方得分区得分，不限刺或切的方向，不依赖技能名字。同一击跨球或跨剑段只算一次。
- 刃碰刃、刃碰对方护手中性，不直接得分也不免伤；柄、机械臂、底座、地面等按已确认犯规规范处理。同一步犯规优先于命中，数值／证据故障另报错误。
- 暂用几何触碰，不设未标定的最小力度或速度。慢触碰是本任务允许的策略，需记录其速度分布；不能事后把它当作弊。
- 候选固定 1 ms 物理、10 ms 控制、20 ms 策略观测。同一物理步双击记 0/0；单方有效命中 +1/−1；单方犯规 −1/+1；双方或可靠证据仍无法归责的犯规均 −1；有效超时 0/0。首版无优先权或跨步还击窗口。
- 候选正式回合 30 s，双方共同准备完成后计时；准备耗时仍算训练交互成本，准备超时必须有界且作为重置错误。30 s 必须结合最终动作周期再检验，不能导致动作未完成被误判失败。

这不是完整剑道、HEMA 或奥运击剑。借鉴的是“明确有效区域与合法武器接触”的做法：FIK 规则第 12–14 条还包含姿势、剑的部位与击打要求，不能把几何触碰声称为正式剑道一本；FIE 的不同剑种也有不同命中与优先权定义，不能直接混用。此处删去人类主观裁判与移动步法，以适应固定机械臂和可重复仿真。[FIK 正式规则](https://www.kendo-fik.org/wp-content/uploads/2025/04/Regulations-of-Kendo-Shiai-and-Shinpan-EN_Jul2023.pdf)，[FIE 技术规则](https://static.fie.org/uploads/40/204126-Technical%20rules%20August%202026%20ang.pdf)。

### 多个得分位置不等于画三个球

三个球相互重叠，本质是一块连通区域。仅报告命中了哪一个球会重复计数，且允许所有分数都来自最容易碰到的一点。因此要分开做三件事：

1. **主比赛**：整块并集有效、各处同分、自由选择攻击位置，不按动作标签额外发奖。
2. **位置统计**：按实际首次入靶点，在守方局部坐标中分为低／中／高 × 左／右六格。候选高度分界为 0.975、1.125 m；局部 Y 为左正，Y=0 归左，高度等于边界归上格。该划分只是报告协议，六格的动态可达性仍要逐格验证。跨多个位置同时入靶的事件记为 `multi_contact`，单独报告，不人为制造多个成功覆盖。
3. **位置条件专项测试**：每回合公开给双方同一个指定有效子区，均衡测试各位置。其他区域不计分但原有碰撞／犯规规则不变。裁判必须检测“有效子区本身”的进入，不能只过滤整个并集第一次进入的位置，否则先经过非激活区的合法轨迹会漏判。专项模式及激活区域进入共同任务身份与观测。

专项模式检验是否**能**适应不同位置；自由对打检验是否**会**自发运用这些能力。训练可包含公开、均衡的位置条件课程，但它是不同任务模式，其成绩不能混入自由对打胜率。若自由对打仍只攻一个点，需求 1 尚未满足，不能用专项视频替代它；要检查策略、奖励与对手覆盖，再按新版本复验。

## A1 动作库如何构建

### 数据的角色和局限

[ASE 剑盾动作](https://github.com/nv-tlabs/ASE/tree/6f9b4f1f289603eee6a4f45d082bc6e6d83fecec/ase/data/motions/reallusion_sword_shield) 提供连续运动参考，但原始人物有躯干、腿和盾牌，不等于本机械臂的关节空间或专家实战策略。只参考持剑手、剑轴方向以及准备—击打—随动—回收的连续形状，经过坐标变换、尺度适配、限位 IK 和动力学验证；不直接复制人体关节、不继承盾牌防守能力。

A1 的主线是“数据参考加工程验证的有限技能”，不是已经完成端到端模仿学习。缺失或无法重定向的动作可以人工补全，但逐项记录来源，不把手工动作宣称为数据学得。取得和使用数据前遵守 [来源与再分发说明](../motion_skills/plan1/SOURCES.md)；本分支不包含原始或派生动作数组。

### 功能覆盖优先于姿态数量

十个静态守势与五种切击仍是 [需求清单](../config/a1_pose_requirements_v1.json)，不是已实现数量。先覆盖至少三个实测来剑方向，包括左右差异和上下／斜向变化；同时覆盖不同高度与横向位置，再逐步补齐名称。直刺、左右切、上下斜切可作为候选，但所有名字必须由实际剑身路径核对。

每条技能存储入口条件、连续关节参考、有效攻击阶段、完整回收、允许切换点，以及已验证的目标位置、来剑范围和启动时窗。用连续插值与重定时保证入口/出口位置和速度衔接，不逐帧任意换 pose。路径平滑只是必要条件：实际接触、限位、跟踪与恢复都必须过关。

防守先验证真实碰剑是否在入靶前改变来剑轨迹，然后继续观察到双方完整回收和下一次合法选择机会。方向正确、选了 Parry、发生碰剑都不能取消真实得分。建立明确的安全分支点，避免超长不可中断动作使 A1 来不及应对；不能允许任意瞬时切换制造不连续参考。

当前候选仅供检查：[动作图](../config/a1_direction_candidates_v1.json)、[覆盖与失败](a1_action_coverage_zh.md)。原小球下的低挡在扩大区域后出现提前入靶，必须重做，不能直接拿去训练。

## A2 如何学习及如何证明灵活

A2 每个策略周期输出七维有界动作，经过共同参考命令约束和同一物理伺服执行，不直接改写 `qpos/qvel`。受阻时不能无限积累目标。A1 的轨迹参考也要经过同一约束；若因此改变动作，要重新验证 A1，不能只限制 A2。[具体控制及观测设计](a2_system_design_zh.md)。

训练顺序是：无专家轨迹的短控制／到达课程 → 共同规则下自博弈 → 冻结评估。课程可以提供距离反馈帮助从连续空间探索，但单列训练目标、交互成本和结果；正式比赛不按动作次数、抖动或防守名称发奖励。A2 不能读取 A1 库作为自己的动作模板后仍称“从关节自主探索”。

两类训练各有冻结历史对手池，避免当前双方同时更新造成非平稳反馈。共同评估分成可用于修复的开发门禁集和训练前封存的最终留出集，二者不能混用。既有 PPO 工具可借用采样与更新结构，七维连续动作、时长折扣和自身状态仍需明确实现；旧五动作训练脚本不是 A2 入口。

要支持“更灵活”的结论，A2 在相同预算下不仅要有可用攻防，还应在未见方向、时间或目标变化上保持／提高成功率，产生与变化一致的实际轨迹调整。若只对固定 A1 某处漏洞有效，或多样性来自无效抖动，不支持该结论。A2 未胜出也属于有效研究结果，须报告原因而不削弱 A1 基线。

## 公平性及共同观测

双方同时读取同一已完成物理步的快照：双方关节位置／速度、握点与剑尖位置／速度、相对底座与目标几何、公开激活区域、剩余回合时间，以及各自已知的执行状态和命令误差。使用相同坐标约定、归一化和历史窗口。先计算双方动作，再一起推进，避免后调用者偷看本步决策。

不得提供对方技能编号、未来轨迹、内部参考或策略身份。A1 的自身技能状态／mask 与 A2 的自身命令状态是不同执行器的必要信息，不是对方意图。基础信息相同不代表 action space 必须相同——离散先验和连续控制正是研究变量。

仿真可直接提供这些物理量，无需先做视觉。但实机只靠自身编码器无法获得对手剑的位置；真实感知或外部跟踪是独立后续工作。当前比较只证明仿真内性能，不声称已解决 sim-to-real。

两个家族共用关节边界、力矩限制、低层控制、命令变化率与受阻规则。截图的电机转速和理想输出力矩不是已标定动态上限，当前调试力矩只能被称为相同仿真条件。每次版本冻结要记录模型、靶区、裁判、观测、时钟、初态与控制器哈希。

主要按**相同模拟交互秒数**比较，包含准备、失败和课程成本；另报策略决策数、优化次数、计算时间、数据与人工设计成本。A1 的动作次数比 A2 少，不能简单按 transition 条数给两者不同物理训练时间。折扣也按实际持续秒数计算。

## 分阶段验收与停止条件

以下为建议验收协议，数量／阈值应在正式训练前冻结，不能看完结果后改门槛。通过只说明在该测试集内可用，不保证对任意 A2 动作都能格挡。

| 阶段 | 最小测试与输出 | 不通过时阻止什么 |
| --- | --- | --- |
| G0 共同规则与物理 | 新靶区动态可达；边界、重叠去重、同一步双击/犯规、合法武器接触、重置和镜像事件；原生连续扫过检查；数值步长敏感性 | 禁止据此宣布动作合格或开始正式训练 |
| G1 A1 动作能力 | 至少六个方向×位置用例覆盖低/中/高及左右、至少三种实测来剑方向；每个有进攻对静止、对应防守、晚/错控制、完整回收、镜像及微扰 | 禁止用不合格库训练；保留失败，不用调奖励遮掩 |
| G2 A2 和共同控制 | 零输入、单轴、极限附近、受阻后释放、连续反向、状态隔离、重置、实际速度/跟踪；通过后允许无专家控制课程与有界短自博弈，检查采样/收益/连续动作 log probability | 禁止把命令层测试当作完整 A2，禁止未经短训验证直接长训 |
| G3 两者各自能力 | 学习后各自对共同开发门禁集的合法威胁、开放目标及退化对手测试；报告逐位置逐方向攻防、恢复、犯规、超时和错误 | 任一方不会进攻/防守、持续卡住或数值不稳时，继续修复/学习，禁止进入正式优劣结论 |
| G4 预算化训练与冻结比较 | 短训链路有效后按预算训练；能力合格后固定权重和归一化，交换位置、多种子、用未用于开发的封存留出集评估 | 不能把自博弈奖励上升直接当作更强，不能边评估边学习 |

G1/G3 建议每个主要用例每侧先做 20 次预先生成的时间／位置小扰动，攻击命中且恢复、防守无入靶且恢复各至少 16/20；分母保留全部尝试，另列故障。允许未成功的部分仅限合法战术未命中／漏防：任何数值或证据故障、关节硬约束失败均须停止修复，不能靠另外 16 次成功抵消后放行。这个 80% 是排除“偶尔碰巧成功”的工程筛选线，不是统计置信保证。基础确定性正反例、限位与事件契约须全部通过；正式评估报告置信区间和逐格结果。错方向若偶然真实挡住，按物理结果记录，不能强行判失败；需另有已知无拦截的负例验证裁判。

G2 通过只表示可以开始有界学习，不要求尚未训练的 A2 先会对打；环境本身的可攻防性须由 G0/G1 的物理控制验证。G3 的能力门约束正式比较，不循环阻止 A2 用学习获得该能力。

完整动作诊断按实际完成条件延长到预定有界最长观察时间，未完成标记截断，而非自动判漏防。正式比赛仍按独立比赛时钟结算；首击后诊断结果不反改比分。测试轨迹包括准备到回收再到下一选择，不只截取出剑瞬间。

G3 额外检查一直等、一直攻击、一直防守、机械臂遮靶、主动制造共同犯规和数值错误。无明显缺陷不要求不犯任何战术错误，也不要求 A1 保护所有未见轨迹；要求的是已定义基础任务不存在系统性盲区或可稳定刷分的漏洞。

### 自然性与演示视频

在无接触阶段测实际关节/剑尖速度连续性、归一化加速度与 jerk、非必要停顿和相邻技能接续；接触冲量阶段单列，不能为降低 jerk 删除真实挡剑物理。指标归一化方式与阈值在短试验后、正式训练前冻结，并对两者一致。

最终提供同视角、原速、不挑选结果的连续回合，叠加目标格、得分/犯规、当前时间及技能完成/截断状态；包含进攻、防守、反击和失败。至少一组自由对打与一组均衡专项测试分开展示，附全部回合索引。邀请未看策略标签的队友检查动作是否连贯，视频观感不能取代物理及计分验收。

## 最终实验如何支持结论

- **独立能力**：A1、A2 先对相同开发门禁威胁/目标做逐方向逐位置攻防并修复；最终在封存留出集含未见时间和小位置变化上确认，单独报告恢复与连续响应。
- **主比较**：同预算 A1 对 A2，至少三个训练种子，配对测试种子并交换槽位。报告命中胜、犯规胜、双击、双犯规、超时和数值故障的数量及比例；不能只给剔除错误后的胜率。
- **泛化与灵活性**：对固定保留策略池、未见启动时间和目标扰动测试，报告性能下降、响应时延、实际攻击方向/入靶位置分布；小扰动不得改变已冻结正式物理规则。
- **消融**：在预算允许时检验 A1 只有单方向库与完整库的差别，以及 A2 是否需要无专家到达课程。主对照始终用完整且合格的 A1，消融不能替代它。

开发门禁集允许反复调试，不能当最终未见结果。最终留出对手、扰动种子和统计协议在训练前封存；查看后若据此调参，旧集降为开发数据，新结论需新的留出集。全体尝试均记账，不用重试丢弃失败来改善成绩。

自由对打多样性若不足，先如实标为未满足需求，再判断是动作空间、威胁分布还是奖励诱导集中；不能在测试中临时规定 A2 必须出某个动作来制造“自主灵活”。A2 的优势要与多样性、合法成功及适应性共同出现才有解释力，不能只凭其中一个指标。

## 已有证据与不能继承的结果

[打包摘要](plan2_verification.json) 保存原报告指纹、关键数字与失败。详细本地轨迹没有随 Git 上传，摘要不冒充可重算的全量数据。

- 旧事件契约：70 个单元测试及 18 个合成场景通过；证明旧事件接口，不证明新多区裁判已实现。0.7 ms 间隔的命中在不同步长/相位可能得到不同双击分类。
- 七条已有原生轨迹做靶区影子分析：原低挡在小球下不失分，但紧凑并集约 3.432 s 已入靶，早于约 4.372 s 碰剑；说明扩大区域必须重验防守。
- 独立关节空间检查：768 个不同向量双侧共 1536 次静态计算，后续 20 次目标搜索得到三个高度的双侧静态无代理重叠见证。它不是六格覆盖、不是从准备位可执行路径，更不是 A2 学会了进攻。
- A2 命令约束：20 个离线测试通过；示例受阻 1 s 后参考偏移从无界约 2 rad 限为 0.10 rad。这只验证参考命令契约，示例参数未定为正式值，未验证原生接触动态。
