# A2 连续关节策略与共同平台设计

日期：2026-11-23。状态：系统设计和离线命令验证，不是已经接入的 A2 训练环境。共同任务见 [评分规范提案](scoring_spec_v3_proposal_zh.md)，最终四项要求与测试协议见 [Plan 2](plan2_zh.md)。

## 两种策略只在动作表达和先验上有意不同

A1 选择经过验证的连续技能，A2 从七关节目标增量学习运动。两者共用同一个物理步进器、裁判、接触归责、低层控制及基础观测。物理槽位 `a1/a2` 不是策略类型；交叉比赛必须允许两种策略交换位置。

建议两者使用同一类 PPO 学习框架，分别采用离散技能头与连续动作头。PPO 可用于离散和 Box 连续动作空间，但这不意味着现有 A1 代码已经支持 A2；旧代码的五动作、mask 和 rollout 假设仍需明确改造。[PPO 官方接口](https://stable-baselines3.readthedocs.io/en/master/modules/ppo.html)

## 动作和目标命令

A2 每 20 ms 产生 `a ∈ [-1,1]^7`，依次对应 J0 至 J6。每个 10 ms 控制步使用这个动作，名义目标增量为 `v_ref_max × 0.01 × a`。`v_ref_max` 是待选择的参考命令速度，不是实测电机极限或实际关节速度保证。

不能无限执行 `q_ref += Δq`。关节受阻时，无界参考仍会持续远离实际状态，解除接触后可能突然追赶。采用显式的上一接受参考 `q_ref`，同时限制：

- 参考位于确认关节边界的内缩区间；
- 每次参考变化不超过共同参考速度预算；
- 参考过度偏离实际位置时，禁止继续向外累积，允许保持或逐步退回。

在某轴上，设实际位置为 `q`、上一接受参考为 `r`、控制周期为 `h`、参考速度上限为 `v`、误差带为 `e`，允许下一参考的区间为：

`[q_min+m, q_max-m] ∩ [r-vh, r+vh] ∩ [min(r,q-e), max(r,q+e)]`

把请求 `r+vha` 投影到这个区间。合法的上一参考仍在区间中，所以零动作严格保持参考，不因碰撞强制瞬移回实际位置。只保存实际接受参考，丢弃被阻塞增量，不保留后台累积目标。实际 `qpos/qvel` 不裁剪、不重置；超物理边界的输入直接报错。

A1 的轨迹参考若接入同一约束器，也可能改变接触与回收，必须重新验收，不能只约束 A2 或继承旧视频结论。位置伺服、命令上限和碰撞是不同层次；MuJoCo 的软接触与动力学仍需原生测试。[MuJoCo 计算说明](https://mujoco.readthedocs.io/en/stable/computation/index.html)

## 已做的离线接口验证

纯命令函数的 20 项测试通过。示例把实际关节数值保持不动 1 s：无界累加目标偏移约 2 rad，约束后停在 0.10 rad；下一控制步反向请求退至 0.08 rad，零动作保持。两侧状态、输入数组和输出数组互不共享。

其中 `2 rad/s`、`0.10 rad` 误差带和 `1°` 内缩只是故障示例参数，尚未选为正式默认值。尤其较小误差带会改变 A1 既有跟踪误差和动作轨迹。该测试没有 MuJoCo 积分，不能证明实际速度、力矩、接触或稳定性安全。

证据：[公开摘要与原报告指纹](plan2_verification.json)、[离线参考函数](../tools/audit_a2_command_contract.py)。完整历史记录 `outputs/scoring_design_v1/a2_command_contract/summary.json` 未随 Git 分发；可从源码重跑该离线审计。

## 共同观测

基础物理观测建议双方都提供以下信息，全部来自当前同一已完成的物理状态：

| 信息 | 用途与限制 |
| --- | --- |
| 双方关节位置和速度 | 判断姿态、运动和机械臂接近；仿真可直接提供，实机等价信息尚未解决 |
| 双方握点和剑尖的位置及速度 | 表达整条剑的空间运动；只有剑尖速度不够，握点也可能在运动 |
| 自身接受参考与实际关节的误差、上一动作和限幅标记 | 让策略知道自身命令是否被阻止，避免隐藏积分状态 |
| 靶区与底座相对位置、共同回合剩余时间；专项模式中的公开激活子区 | 支持空间判断和有限回合决策；双方知道相同任务，剩余时间不是对手未来动作脚本 |

位置与速度转到各自一致的局部坐标并统一归一化。A1 的自身可用技能 mask 与 A2 的自身命令边界属于各自已知执行状态；不向任何一方提供对手技能名、未来轨迹、内部目标参考或决策意图。

双方先完成同一受控准备阶段，再同时开启策略与正式比赛时钟。不能让 A2 在 A1 尚未就绪时提前行动。两方决策都使用同一个步前快照，然后一起提交命令，不能让后调用的一方看到另一方本步刚选出的动作。准备失败作为重置错误保留，不生成虚构胜负。

第一版可使用短历史帧堆叠，减少引入循环网络的工程量；双方使用相同历史长度与更新周期。它不能消除所有部分可观测性，但无需视觉模型就能先验证仿真中的反馈。当前 `physical_observation` 只有自身关节、对手握点／剑尖位置和剑尖速度，尚未实现上述完整方案。

## 训练课程与风险

1. 先完成零输入、单轴小增量、限位附近、受阻命令、双方镜像及错误处理的原生测试。
2. 进行不含专家动作的关节控制和目标到达课程；如使用距离辅助收益，必须标为预训练，计入交互成本，不混入正式比赛成绩。
3. 进入共同评分规范下的自博弈，对手从冻结历史快照采样。开始时的有限探索不是让机器人直接在全关节空间随机跳位置。
4. 用共同保留对手和种子做短训练检查，排除不行动、制造犯规和数值故障等退化，再扩大训练预算。

A2 从连续关节探索出可靠接触行为仍然比选择已验证技能困难；控制课程不是成功保证。预算不足时应如实报告学习进度，不能中途把 A2 改成选择 A1 技能却仍称为连续控制对比。

## 时间与策略数据

A2 每 20 ms 是一次策略选择；A1 只有执行器允许选择时才产生 actor 决策，忙碌续播不重复计为选择。折扣使用实际秒数：`gamma(Δt) = gamma_per_second ** Δt`。额外的连续收益按时间积分，不能按动作调用次数发放。

连续策略记录原始采样动作及其对应 log probability；约束后的实际目标单独记录，不能把投影命令冒充原始采样动作。现有 A1 rollout 的五动作接口也不能直接装载七维动作。

每方独立保存随机数状态、历史观测、策略隐藏状态和 `q_ref`。共享冻结权重不意味着共享这些状态。每局重置清空，冻结评估时禁止优化器、归一化统计和对手权重更新。

## 最终比较与放行条件

两种策略使用相同正式计分、物理和观测。训练时的动作先验与课程可以不同，但分别说明并核算；主要比较相同模拟交互预算，另报计算时间。评估同时包含互打和共同未见对手，交换场地，分别统计命中胜、犯规胜、双击、双犯规、超时与数值错误。

快照分别保存共同比赛身份和各自策略身份：共同身份包含靶区、物理、时钟、观测、初态和裁判；策略身份包含 A1 动作库或 A2 动作尺度、命令约束、训练课程与算法设置。不能关闭旧的兼容检查来强行加载 A2。

“A2 更灵活”是待检验假设。A1 和 A2 分别通过合法进攻、分方向防守、回收与连续响应的独立门槛后，再在共同未见方向／启动时间／目标位置上比较成功率与真实轨迹适应。只有动作熵变大、抖动增加或利用弱 A1 获胜不能支持该结论；A2 没有胜出也应如实报告。多位置专项成功与自由对打的自发多样性分别评价。

正式放行前仍需：选定共同命令参数、实现共同观测与 A2 适配器、完成原生受阻和接触测试、重新验收 A1 动作、验证裁判和 PPO 数据链。当前只完成命令层离线验证，A2 尚未开始正式训练。
