# A1 首版动作包与训练策略（2026-11-25）

本版先交付**有明确验证范围的动作素材与开发工具**。不再要求挡住所有连招；保留可用动作，公开快速连续进攻的弱点。它不是训练完成的 agent，也不是新动作库已经完成 PPO 接入的声明。

## 1. 现在有什么

- 6 类进攻：左→右下斜劈、右→左下斜劈、左→右上挑、右→左上挑、正下劈、直刺。面向对手定义方向，不以镜头方向定义。
- 左、右、高位防守家族，细分为对应六类来剑的 6 份防守素材；保留用户认可的竖剑／斜上持剑风格。不是一个静止姿势自动挡住所有来剑。
- 独立的准备、回守、换侧边与部分经验证的拦截／卸载阶段。每条边有真实入口和出口；不能任意跳 pose。
- 合并目录有 **34 条边、13 个命名节点（12 组不同关节坐标）**，含 18 条过渡候选。目录连通不等于所有连续实战路径已合格；34 条边不能全部宣传为已通过物理验证。

六种进攻各有对应的单轮成对防守证据：同一入口、同一攻击、同一时钟下，等待对照会中靶，而指定防守在完整观察窗内未被该攻击击中。这是 **6/6 已选定匹配案例**，不是“任意攻击有 100% 防守率”。包内证据索引收录这六对标称案例；时机、槽位、连续执行的扩展记录另列在 `docs/a1_validation_scope.json`，原始大文件未随包发布。

已有扩展包括右侧上下切各在 0.65／0.75／0.85 s 三个离散防守启动时机的测试（进攻均从 0.75 s 开始）；交换槽位仅补测 0.75／0.75 s 标称时机。另有左下斜劈两轮无重置、正下劈与直刺的重复交互、右挡的当前物理观测触发及分段回守。不存在对所有技能任意排列组合的保证。

**保留的反例：**左下劈接立即反向上挑，原回守路径反应过晚；另一个提前接触的改进候选仍在 7.651 s 漏防。没有删掉第二刀、放慢对手、取消有效命中或提高电机力矩来改成绩。失败替代动作不进入可用素材。无法挡住某个合法连招可以是策略弱点；没有真实有效进攻／防守、无法连续执行或规则不公平则仍是平台缺陷，不能留给 RL 修复。

## 2. 共同物理与得分

固定底座、原尺寸机械臂、1.080 m 竹剑、底座距离 1.75 m。使用确认后的关节边界及 J3 伸直零位映射，内部数值保持 CAD 弧度。不缩放模型、不做角度绕回、不直接改 qpos 模拟运动。共同仿真力矩上限为 `[5,80,15,20,3,3,2] Nm`；特别保留 J4=3 Nm。参考曲线速度上限 2 rad/s 不等于碰撞后实测速度的硬保证，也不是实机认证。

三个互不重叠的球形练习靶区，半径均为 0.10 m；坐标在受击方底座局部坐标系：+x 朝对手、+y 向自身左侧、+z 向上。

| 靶区 | 中心 (m) | 一次有效命中 |
| --- | --- | --- |
| 左侧 | (0.32, +0.20, 0.93) | 攻方 +1，守方 −1 |
| 右侧 | (0.32, −0.20, 0.93) | 攻方 +1，守方 −1 |
| 中上 | (0.32, 0, 1.22) | 攻方 +1，守方 −1 |

三点同分。有效剑身而非仅剑尖参与判分；剑碰剑／护手是中性接触，不加分、不授予格挡免伤。防守成功诊断需先有有效威胁、先物理拦截且完整攻击／回收／退出窗口不再入靶；仅碰剑不算成功。

犯规沿用已确认的接触点运动启发式归责：单方主动撞击为责任方 −1、对方 +1；双方主动或责任不清为双方 −1、不判胜者；自身碰撞／碰地由自身负责。剑柄、机械臂和底座等非法接触不能当合法挡剑。该归责不是现实赛事裁判。同一物理步犯规优先；有效同时命中双方 0；正常超时双方 0；数值／证据故障报错，不当平局。正式比赛首个终局事件结束；动作验收另外记录全窗，避免隐藏迟发漏防。

**实现状态必须分开：**当前新动作证据使用完整三靶的离线几何审查；旧 `sim.a1_env` 仍是旧单靶、五动作训练环境。三靶同时事件／犯规优先接入在线环境后还需要重验，不能把旧环境的训练成绩当本规则成绩。

## 3. A1 学什么，怎样兼顾进攻和防守

A1 学的是**何时等待、选择哪条当前可用技能、何时准备／换侧／回守**；关节轨迹由动作库执行。A2 以后从连续关节目标增量学习，两者只在动作接口上不同，不能使用不同得分规则。

奖励只来自共同物理终局。**不为攻击按钮、防守按钮、切换次数、碰剑次数或某个技能名称发奖励。**也不按三个靶区额外加“花样分”。这样不会因为刷动作／不断假格挡获得收益。

不建议硬规定“攻击 N 秒后必须防守”或强制一攻一守：对某些局面持续施压或持续防守本来合理，强制轮换会使策略可预测，而且人为限制 A1 会污染与 A2 的比较。长时间偏某种行为首先作为诊断，不自动判罚。

拟采用以下训练流程（**待新环境接通后实施，不是已完成训练**）：

1. **小规模闭环检查。** 新动作 ID、真实就绪门槛、三靶裁判、共同观测和快照身份逐项对齐；先跑完整回合与一次 PPO 更新，不直接长训。动作执行中只允许继续，不将强制继续重复记作 actor 选择。折扣按真实秒数，而不是把长技能和一次等待算成相同步长。
2. **平衡学习机会。** 训练批次覆盖左右及中上目标、可进攻的空档和已有成功案例中的可防威胁。不同合法入口／准备过程必须显式提供；不得用中途重置或隐藏对手技能标签帮助防守。若做单靶专项，其任务模式与激活靶区双方可见，专项成绩单独报告。
3. **历史对手自博弈。** 每局开始抽取冻结对手，局内不变；交替物理槽位。保留不同阶段的快照，避免只适应最新对手。额外使用等待、持续进攻、防守／反击型固定对手诊断偏科，但不能把只打固定脚本叫自博弈。当前旧版仅保存最近四个快照，未来需检查遗忘，不默认它已覆盖这些风格。
4. **按缺项补训练，不按动作发钱。** 例如策略能守不能攻，就增加真实有攻击机会的局面／对手；能攻不能守，就增加合法且已知可防的威胁。调整的是训练分布，不是给“按防守”奖励。先核实动作／观测是否有解，再归因于学习不足。
5. **单独验收攻与守。** 检查实际命中、各方向防守、犯规率、连续恢复／换侧和超时。挑 checkpoint 时不得只按平均回报或总胜率，因为平均值会掩盖完全不进攻、某侧不会防守的问题。

建议将每个主要方向／双方槽位各至少 20 局作为第一轮能力检查预算，记录成功比例、样本量和区间；具体通过阈值在正式训练前冻结。未覆盖的时机／对手另建保留集，不反复看测试集调动作。已经用来调试的快速反向连招是开发反例，不再称为未知测试。

这套方法降低纯攻／纯守和动作依赖风险，但**不能在训练前保证网络必然学会**。没有通过独立进攻与防守门槛的 checkpoint 不应作为最终比较模型；需要报告失败原因，而不是给它加动作奖励使曲线好看。

## 4. 对 A2 与最终演示的影响

待集成的共同接口要求：双方看到同一完成物理步的公共状态，包括自己的关节角／速度，对方剑的位姿／速度及共同公开任务信息；A1 另外知道自己的技能执行／可用状态。不暴露对手动作名、动作 ID、未来轨迹、隐藏阶段或对手快照身份。选择同时提交，避免先后手读取不同状态。

A1 与 A2 必须使用同一模型、力矩约束、共同底层控制、三靶裁判、犯规、超时和初态分布。共享控制适配仍未接通：不能悄悄给 A2 加 0.1 rad 跟踪 leash，再宣称与已验证 A1 曲线等价。离线检查已发现它会改写部分命令，需显式选择配置并重验。

先各自通过攻、防、合法性和连续性检查，再冻结 checkpoint 交叉对打；交换槽位、配对种子，同时报告胜负、各靶命中、犯规、超时和动作分布。记录训练交互的模拟秒数，不能仅比较 optimizer 更新次数。A2 获胜不是预设结论；要观察它是否在未见局面产生有效而非抖动／违规的灵活应对。

保留连招弱点也会影响结论：如果 A2 主要靠重复命中 A1 已知的库覆盖缺口取胜，应报告为有限动作接口的限制，不能仅凭胜率宣称它学到了更高水平的击剑。按来剑类型拆分结果，并区分“原本存在应对动作但选错了”和“库中尚无已验证应对”，才能解释差异。
