# A1 新限位下的双机攻防验证

后续已增加真实观测反馈与准备位连接检查；共同准备位的新格挡仍未通过接触验收。当前训练放行状态与视频范围见[反馈与共同准备位验证](a1_feedback_validation_zh.md)。本页保留各自准备位下的原始匹配证据。

当前已有一组通过完整窗口检查的攻击与格挡：无主动格挡时攻击命中，及时格挡后整个 7.5 s 窗口没有攻击方入靶，双方完成回收；交换两台机械臂的攻防角色也通过。晚格挡和反方向动作仍被命中。

这一步证明了特定初态下的物理攻防机会，不是完整 A1 动作库。测试程序定时请求动作，尚未通过观测自主选择；攻守使用不同准备姿态，它们之间的双向衔接也未验收，因此仍不能启动新版 A1 长训。

## 固定条件与验收

两机底座间距保持 1.75 m，目标球半径保持 0.06 m，原尺寸机械臂与竹剑、代理碰撞模型、惯性和力矩上限不变。使用用户确认的 J0–J6 角度范围、RK4、1 ms 物理步长、10 ms 控制周期。

新增 `sim.limited_duel.build_limited_duel` 在两个槽位实际设置确认限位，并使用显式合法初态；不修改 CAD 零位和 joint ref。旧双机入口的 ±π 默认值保留，不自动应用到新验证。

`sim.constrained_trial.run_constrained_trial` 只通过原生力矩受限伺服执行连续参考，不在运行中重置 qpos。记录每个物理步的实际状态、保持的控制目标和即时参考，保留接触、命中、犯规及数值故障。首击结算与完整窗口验收分开：首次命中后继续安全运行并记录后续入靶；犯规或数值故障使完整动作验收失败。

`sim.constrained_validation.compare_trial_directories` 要求双方初态、攻击曲线、攻击启动时刻、物理参数、规则、源版本和观察窗口匹配。防守必须同时满足：

- 无防守对照中的攻击确实命中且完成整个动作；
- 防守试验完成全窗口并返回稳定状态；
- 命中前存在达到原阈值的真实合法武器接触；
- 从准备到回收的整个窗口没有攻击方再次入靶。

## 早期攻击与保留的失败

攻击从 canonical OxRight 出发，到达指向原靶区的倾斜剑位，再返回同一关节状态。前进和返回各 2 s，0.75 s 开始，完整观察到 5.5 s。

在双方保持同一 OxRight 初态时，攻击方在约 2.411 s 命中；交换两个物理槽位后得到相同命中时刻。双方最终稳定，实际关节无越界、无代理穿透。该条攻击最大关节跟踪误差约 0.050 rad。证据分别位于 `outputs/a1_attack_native_v2/`、`outputs/a1_attack_native_mirrored_v1/`；补全异常帧记录后的再次运行位于 `outputs/a1_attack_native_v3/`。

这证明该攻击在上述保持对照下有效，不证明它能承受格挡接触。原攻击的 J5 参考离下界很近，接触鲁棒性须另验。

从 OxRight 直接换到现有五个守势的第一组试验，没有通过完整防守验收：FoolsLeft、PlowLeft 触发犯规；OxLeft 出现证据／数值故障；PlowRight、Kron 仍被命中。结果保存在 `outputs/a1_defence_native_v1/`。

中心线上指的竖向剑身在静态几何上可以拦截，但原生试验暴露出两类问题：大幅转动时跟踪滞后；来剑在命中前仍有明显侧向偏移，中心线姿态会过晚才碰到剑。随后的小幅换势试验保存在 `outputs/a1_small_parry_native_v1/`，没有通过完整窗口验收。

依据实际来剑轨迹建立的偏置拦截，在约 1.878 s 发生合法碰剑，但第一条试验约 2.126 s 因进攻侧 J5 触及下界而失败。此前合法武器冲量约 1.31 N·s，没有将这次局部拦截算作成功防守。证据位于 `outputs/a1_offset_parry_native_v1/`。

## 新攻击与格挡的构造

防守姿态已尝试采用较小的腕部动作，以及至少 0.05 rad 的规划内界、J5 下界 0.15 rad 的额外规划余量。这些只是规划范围，不改变物理关节限位。

原攻击保持原先精确手柄／剑轴提示时，增加 J5 余量的两个 IK 探针均未通过；失败记录位于 `outputs/a1_attack_margin_probe_v1/`。

新攻击明确改用了自行设计的关节空间终点：与旧提示相比，握点偏差约 6.63 mm、剑轴偏差约 1.97°；没有把旧精确 IK 失败改名为成功。新终点 J5 距下界 0.10 rad，但起点仍只有 0.005 rad 余量，不能称整条轨迹都有充足余量。攻击从 canonical OxRight 出发，2 s 前进、2 s 返回，没有中间长时间保持。数值轨迹和构造记录保存在 `outputs/a1_joint_attack_margin_candidate_v1/`。

格挡采用本机局部坐标下握点约 `(0.50, 0.14, 0.55) m`、剑轴向上的偏置拦截位置。其准备姿态与格挡姿态仅相差 J4 的 0.25 rad；0.5 s 到位、2 s 保持、1.5 s 返回。该候选避开了此前大幅全臂移动造成的跟踪滞后，也在来剑接近目标前布置了拦截位置。轨迹位于 `outputs/a1_offset_parry_probe_v1/offset_x50_y14_J4_plus25_path.npz`。

命中对象、剑和机械臂尺寸、关节硬限位、原力矩上限及计分规则均未改变。新攻击重新跑了与格挡相同初态的保持对照，不继承旧攻击的证书。

## 完整窗口正反例

下表时间均从试验开始计，攻击在 0.75 s 启动。除注明入口失败的试验外，均完整运行至 7.5 s，而不是碰剑或首击后就停止检查。

| 条件 | 防守动作启动 | 结果 |
| --- | --- | --- |
| 保持准备姿态的匹配对照 | 不主动格挡 | 2.4804 s 攻击入靶，随后完成回收 |
| 及时格挡 | 0.75 s | 1.953 s 首次有效碰剑，全窗口无攻击方入靶 |
| 延迟启动样本一 | 0.90 s | 全窗口无攻击方入靶 |
| 延迟启动样本二 | 1.00 s | 全窗口无攻击方入靶 |
| 太晚格挡 | 2.50 s | 2.4804 s 已被命中，格挡失败 |
| 反方向腕部动作 | 0.75 s | 无有效提前碰剑，2.4804 s 被命中 |
| 交换两机攻防角色 | 0.75 s | 匹配对照命中；及时格挡全窗口无攻击方入靶 |

及时格挡在原匹配对照首次命中前累计合法武器冲量约 3.388 N·s；镜像试验约 3.383 N·s。两者都满足原阈值，完成回收且没有实际关节越界、限位辅助力、非法接触或数值故障。存在接触求解允许范围内的小穿入，不能将其描述成几何零穿透。

另一个 1.25 s 启动试验因 `entry_not_settled:a2` 失败：在约 1.23 s 已发生的被动碰剑扰动了防守方，启动时不再符合当前入口条件。它不是完整防守通过，也不是可用于学习奖励的正常败局。0.75、0.90、1.00 s 的离散成功样本不构成整个时间区间或任意来剑的保证。保持对照和晚格挡也存在被动武器接触，但仍被命中，进一步说明“碰到剑”本身不能算防守成功。

本地原始证据：

- `outputs/a1_joint_margin_native_v1/`：新攻击、及时格挡与晚格挡的完整匹配对照。
- `outputs/a1_joint_margin_controls_v1/`：反方向对照与 1.25 s 入口失败。
- `outputs/a1_reaction_window_v1/`：0.90、1.00 s 启动样本；仍为定时试验，不是反应策略。
- `outputs/a1_joint_margin_mirrored_v1/`：交换攻防角色的两轮匹配对照。

每轮目录保存参考、逐物理步实际状态、接触及命中记录、初态和源哈希。这些本地生成证据不自动纳入 Git。

## 进入 A1 训练前还缺什么

下一步先解决攻守准备姿态的衔接，让同一个 agent 能合法地从当前实测状态进入攻击或格挡，并返回可继续决策的状态。不能在选招时瞬移到本轮各自的初态。受碰剑扰动后的进入与恢复必须单独验证，不能简单删除稳定条件来放行动作。

随后用当前可观测的对手剑位姿／速度触发格挡，检查感知到决策的时延是否落在真实可用的启动机会内；不能使用未来攻击脚本或固定绝对时间冒充反馈。最后再扩展攻击方向、格挡覆盖和小幅初态扰动，并检查连续攻击、防守、反击和一直等待是否造成退化对局。

上述条件通过后，才更新 A1 的动作图、action mask、执行状态观测和快照身份，接入新限位训练。当前所有新候选仍为 `admitted_to_training=false`；旧五动作 checkpoint 不可直接继承。

## 使用接口

```python
from sim.constrained_trial import ScheduledReference, hold_reference, run_constrained_trial
from sim.constrained_validation import compare_trial_directories
from sim.motion_spline import C2JointSpline

# time_s 和 qpos 来自已检查、以 0 秒为起点的具体候选。
attack = ScheduledReference(C2JointSpline(time_s, qpos), start_s=0.75)
guard = hold_reference(defender_ready_q, duration_s=4.0)
result = run_constrained_trial(
    {"a1": attack, "a2": guard},
    "outputs/new_unique_trial", duration_s=7.5,
)
```

输出目录必须是新的。独立静态 IK 解不能直接替代已连接路径的节点；不同准备姿态、动作曲线或时钟都需要新匹配对照。当前接口不接入旧五动作 actor，也不自动授予任何动作训练资格。

本轮代码回归 454 项通过。它验证接口和判定逻辑，不替代本页记录的实际攻防证据，也不代表已经得到训练策略。
