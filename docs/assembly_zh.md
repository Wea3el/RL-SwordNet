# 四孔接口与单臂持剑装配

2026-11-21：机械臂的完整底座侧装在人形躯干右肩；末端通过四孔板和短夹环，横向握住护手下方的柄部。躯干、肩适配板、原固定底座和运动链属于同一固定装配，不再放置独立目标盒，也不再沿四孔面法向插剑。原始 `robot.xml`、`scene.xml`、CAD 网格和机械臂尺寸均未改动。本阶段检查装配和低速持剑，不验证击剑或实机结构强度。

## 完整底座侧装在右肩

世界坐标约定为 +X 向前、+Y 向左、+Z 向上。假人有胸腹、头颈、肩部、固定左臂和落地支架。当前上身按原假人参考几何放大 2 倍，以匹配原尺寸机械臂；这是大尺寸仿真假人，不是 1:1 成人。右肩适配板外侧安装点为世界 `(0, -0.572, 2.050)` m。

机械臂 J1→J6 的关节中心路径约 1.223 m，J1→实际握点路径约 1.304 m；它们不是严格的人体骨骼测量。将假人同步放大后，固定左臂肩中心→腕路径约 1.272 m，左右臂的量级接近，不再用成人大小的躯干配超长右臂。

| 人形尺寸 | 原假人 | 当前配置 |
| --- | --- | --- |
| 胸宽 | 0.46 m | 0.92 m |
| 双肩最外宽 | 0.56 m | 1.12 m |
| 胸腹髋合并高度 | 0.78 m | 1.56 m |

`torso.body_scale` 同时缩放胸腹髋、头颈、肩和固定左臂，不能只拉宽胸部。肩参考点同步缩放，再向右偏移未缩放的 12 mm 适配板厚度，让适配板位于圆肩外侧而不把 CAD 框架埋进肩部。机械臂、CAD 底座、肩适配板尺寸、末端夹具和 shinai 均不缩放，原质量与惯量不变。

支架独立设计而非等比例加高：髋部最低点保持在地面上 0.65 m，支柱与髋部搭接 0.04 m，底盘接地；当前地面至头顶约 2.96 m。修改 `body_scale` 后支柱高度和查看相机自动适配，仍须重跑碰撞检查。人形碰撞目标也随之变大，后续双机器人实验应使用同一固定配置，不能把不同目标尺寸混进策略性能比较。

原 CAD 的固定底座不是一个独立 base body，而是 25 个固定网格；J0 运动链另从 `rotating_base_platform` 开始。固定底座的 `Spacer_Plate` 底面位于 CAD `z=-8 mm`，是外轮廓约 240×240 mm、开口约 200×200 mm 的方环，不能当成已有四孔法兰。

装配将 CAD 底环中心 `(0,0,-0.008)` m 对齐右肩安装点，并对**固定底座和全部运动链一起**施加绕 X 轴 +90° 的旋转：CAD +Z 变为人体右侧 −Y。J0 因而位于肩安装面外约 158 mm，轴向变为世界 +Y。场景 floor、灯光和世界重力不随之旋转。肩适配板覆盖方环而不是仅接到中间空洞；实体紧固方式仍需机械设计确认。

## 安装位置来自现有网格

`sim.inspect_mount` 在 `End_effector_Block.stl` 中查找同一平面上的一个矩形外边界和四个圆孔边界，并交叉检查原始 STL/XML 与 MuJoCo 编译后网格的坐标。找到的面对应截图中浅蓝色的四孔端面，不是沿 J6 转轴的端面。

| 网格测量项 | 结果（显示值已取整） |
| --- | --- |
| 端面外形 | 50 × 50 mm |
| 两方向孔中心距 | 28.2843 × 28.2843 mm |
| 拟合孔径 | 5.3 mm |
| 孔中心相对端面中心 | `(±14.1421, ±14.1421, 0)` mm |
| 端面中心相对 `end_effector_block` | `(25, -10.9122, 22.4929)` mm |
| 端面外法向相对 `end_effector_block` | 约 `(0, -0.436526, 0.899692)` |

定义安装坐标系 `mount`：原点为端面中心，+Z 为外法向，+X 沿机械臂末端局部 +X，+Y 按右手系确定。安装姿态四元数 `wxyz` 约为 `(0.974600385, 0.223951088, 0, 0)`。完整数值保存在 `config/assembly.json`。该面法向与 J6 轴垂直；本版设计选择 mount +X 为剑轴，因此剑轴平行四孔面，并与 J6 轴近似反向。

这是对三角网格的测量，不是制造图纸。5.3 mm 不能证明孔有何螺纹或适配何种螺钉；孔深、背面空间、配合公差和承载能力仍未知。网格拟合残差也不是加工精度。

复现测量：

```bash
python -m sim.inspect_mount --output outputs/mount_inspection
```

输出 `measurement.json` 与四孔正视图 `mount_face.png`。装配构建会核对原始 XML 和末端网格的 SHA-256；这些文件更新后必须重测，而不是静默套用旧接口。

## 夹具与 shinai 的简化方式

夹具是 6 mm 厚四孔连接板、短托架和一个 25 mm 宽空心夹环，不再有纵向长支撑条。夹环中心位于距柄尾 290 mm 处，距护手靠柄侧约 30.96 mm；夹环覆盖柄尾起 277.5–302.5 mm 区间，位于用户圈出的护手下柄部。夹环径向壁厚暂取 5 mm，内半径按该处柄半径加 0.4 mm 间隙确定。

实际握点相对 mount 为 `(22,0,40)` mm，剑轴沿 mount +X。40 mm 的离面高度使木柄靠近末端但不穿入腕部；22 mm 前移使护手绕开末端鼓盘，不能简单取消。短托架从四孔板接入夹环下侧，夹环包住柄而不是将柄尾插进机械臂。

目前用固定父子刚体连接表达“已经夹紧”，不额外加入手指、抓取自由度、夹紧电机或摩擦抓取求解。这使场景仍只有 J0–J6 七个自由度；也意味着本场景**不能证明夹具不会滑脱或断裂**。可视连接板保留四个通孔，螺栓仅为示意；它们不是确认过的紧固件选型。网格和配置可参数化修改，但不是可直接打印/加工的实体 CAD。

shinai 的外形使用所提供 `shinai_blade.step` 的轴向外轮廓生成，运行时无需 FreeCAD 或 STEP 文件。来源哈希、坐标变换和轮廓记录在 `assets/shinai_profile.json` 中。该近似没有保留四片竹材之间的槽和非轴对称细节，不是原 STEP 的精确曲面三角化。

| 剑参数 | 数值与依据 |
| --- | --- |
| 总长 | STEP：1.080 m |
| 柄长（至护手靠柄侧） | STEP：0.320959 m |
| 实际握点 `shinai_grip` | 距柄尾 0.290 m，护手下约 31 mm |
| 实际握点至剑尖 | 0.790 m |
| CAD 轮廓原点 `shinai_profile_origin` | 保留柄中点，距柄尾 0.160480 m；不是实际握点 |
| 护手外径 / 厚度 | STEP：85 / 5 mm |
| 实际握点相对 mount | `(0.022,0,0.040)` m，剑轴平行面 |
| 剑质量 | 照片读数暂取 0.436 kg |
| 质心 | 聊天给出的估计：距柄尾 0.50 m，不在握点 |
| 剑转动惯量 | 简化杆估计，未辨识 |
| 夹具质量 / 惯量 | 暂取 0.10 kg / 配置估计值，不由外形自动计算 |

具名 sites 包括 `right_shoulder_mount`、`mount_face`、`mount_bolt_0`–`mount_bolt_3`、`shinai_profile_origin`、`shinai_grip`、`shinai_pommel`、`shinai_tip`、`shinai_guard_near`、`shinai_guard_far` 和 `shinai_guard`（护手中面）。外形和惯量仍使用 CAD 轮廓原点；实际夹持和后续重定向使用 `shinai_grip`，不能将柄中点或 `end_effector_block` 原点继续当作握点。

## 运行与已完成检查

在仓库根目录运行：

```bash
python -m sim.assembly --headless --output outputs/assembly
```

需要图片时（有可用 EGL 后端的 Linux 环境）：

```bash
MUJOCO_GL=egl python -m sim.assembly --headless --output outputs/assembly --snapshot
```

只查看装配、保持窗口开启直到手动关闭：

```bash
python -m sim.assembly --inspect
```

交互物理检查使用 `python -m sim.assembly`。仅导出不推进物理可用 `--build-only`。物理检查生成独立的 `scene.xml`、`summary.json` 和 `trajectory.csv`，渲染时另有 `overview.png`、`shoulder_closeup.png`、`mount_closeup.png`。`--inspect` 和 `--build-only` 不产生新的物理验收结果，不能将同目录旧 `summary.json` 当作本次成功证据。

导出的 XML 引用本机原始网格的绝对路径，适用于本机异目录重载，不是跨机器独立资源包。换机器应运行构建命令。单独打开生成的 XML 时必须选择 `assembly_home` keyframe；推荐使用上述入口，它会设置初始状态和控制，不要在 CAD 零位直接开始仿真。

初始剑基本水平朝世界 +X。完整机械臂侧装后，通过一维搜索选择 J0 模型重力平衡角，其余关节保持 CAD 角，再 reset 到该位姿；没有验证从 CAD 零位运动到此位姿的路径。默认检查为 10 个模拟秒：1 秒保持、8 秒 J6 余弦往返、1 秒保持；目标幅度 0.01 rad。较短检查会缩短往返，并按目标速度上限缩小幅度。保留原 position actuators、`implicitfast` 积分器，以及同样受力矩上限约束的模型重力前馈；没有新增实机电机模型。

本次默认配置的测量结果：

- 初始关节角约为 `[0.280127, 0, 0, 0, 0, 0, 0]` rad；源 XML 的零位含义不变。
- 剑轴约为世界 `(0.99984,0.00248,0.01796)`，近水平前指；握点至护手约 31 mm。
- 新增剑和夹具质量共 0.536 kg；固定假人不增加自由度。
- 10 秒检查无 MuJoCo 警告，初始无接触，代理几何最大穿透为 0。
- 静态 J1 模型负载约 71.11 Nm，低于暂定 80 Nm cap；J0 依赖所选初始平衡角而非提高 5 Nm cap。完整动态峰值以当次 `summary.json` 为准，**不是实测电机能力**。

结果依赖当前配置和 CAD 质量。重跑后以新 `summary.json` 为准，不把这些数字当永久验收阈值。

## 碰撞与适用边界

原 CAD 网格仍只负责显示；另加七段机械臂 capsule、开口基座代理、连接板、空心环代理、分段剑身和护手碰撞几何。人形躯干及头、肩、固定左臂有简化碰撞几何，未模拟人体组织或柔性表皮。相邻机械臂代理之间的预期关节交叠用掩码排除；工具与腕部父链、运动机械臂与躯干的碰撞仍启用。刚性连接在同一焊接组中的夹具和剑不互相求接触。

握把（含护手前扩口）用四段平端圆柱、剑身用三段平端圆柱包络，半径取该区间所有轮廓折点和端点的最大值。相邻段轴向无缝、接面截面非零，末端不超过 CAD 剑尖；这种分段外包络仍不等于竹材精确碰撞面。

自动测试覆盖四孔接口、25 个固定 CAD 网格和七个关节的完整肩装变换、夹具连通、近护手横握、七自由度、力矩限额、真实碰撞配对、短程物理往返、失败记录和导出重载。运行：

```bash
python -m unittest discover -s tests -v
```

通过以上检查只说明当前装配和小幅动作在所选代理模型下工作，不说明所有挥剑轨迹无碰撞，不证明真实机器人安全。关节窗口、限速、执行器参数、打印件惯量、握把摩擦和竹剑柔性仍需校准。

侧装会改变所有关节相对重力的负载，本次仅找到一个可保持的低速初始姿态，不代表任意挥剑轨迹可行。后续动作验证必须结合实际输出能力重新确认限额，不能为让轨迹通过而无依据地放宽参数。

下一步是以本次测得的安装面和新握点变换重新做 ASE 轨迹重定向，检查可达性、连续性、速度、力矩与整条轨迹碰撞。旧的末端原点/猜测剑轴下的可达率不能沿用。装配完成不代表 `Guard`、`Stab`、`ParryUp` 已可执行，更不代表 `ParryUp` 能挡住进攻；这些仍须在双机器人布局中验证。
